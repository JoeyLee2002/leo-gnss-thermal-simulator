# 任务模板

这些 JSON 文件是面向用户的任务模板，不需要打开 MATLAB GUI 逐项填写全部参数。

使用方法：

1. 复制一个 JSON 模板并修改少量字段，例如 `durationS`、`timeStepS`、轨道参数或网络预设。
2. 在 GUI 快速开始页点击“任务向导”。
3. 选择模板，输入任务名、时长和时间步长；需要外部数据时选择文件。
4. 软件先执行严格配置检查，检查通过后才允许运行。

模板不能保存 MATLAB 函数句柄。外部软件或复杂数据格式应通过 adapter SDK 接入。
模板不会自动补齐、插值、猜测单位、猜测节点关系或把默认参数当成真实卫星标定结果。

模板格式：`leotherm.simulation_template.v1`。
