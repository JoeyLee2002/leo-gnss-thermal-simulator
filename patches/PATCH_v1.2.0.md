# v1.2.0 补丁说明

此版补齐统一任务报告的阶段分析。基础仿真、扫描、三维、遥测、标定只在实际产生对应结果时加入 PDF 与 Markdown；分析文字由本次数据计算，并配中文或英文图表。

单工况扫描使用案例指标图，不作为趋势证据；三维耦合说明单向边界；遥测报告标明独立性和合成数据属性；标定分开呈现训练、验证和测试误差。未运行阶段继续在验收页标为跳过。

没有评分样本的遥测报告只记录缺失证据，不生成空残差图或验证通过标识。未预热的快速仿真会提示初始温度暂态的影响。项目提供五页中文扫描报告样例，便于直接检查新版排版和内容。

修改前的 v1.1.0 快照已保存在项目旁的版本目录。本版仍需在纯 Runtime 机器上做跨机器验收，数值通过不替代任务级物理验证。
