# Patch v0.12.0: ready-to-open example projects

## User-facing changes

- Added five portable MAT example projects under `examples/projects`.
- Added an Open example project action to the Quick start workspace.
- Added a project index mapping each project to its covered feature path.

## Scientific boundary

The example projects and selection UI do not change the numerical solvers.
The telemetry project uses synthetic data, and the 3-D project uses teaching
meshes. Neither is a mission-specific validation or calibration result.
