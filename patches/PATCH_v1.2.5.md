# v1.2.5 - 轨道坐标记录与遥测状态修正

- 内置轨道从生成阶段记录地心赤道近似坐标定义、原点和来源；经过预热裁剪后保留到仿真结果和报告数据包。
- 报告读取实际的轨道坐标记录，不再将其状态固定写成未提供。外部轨道保留用户声明，历史结果不自动改标为 J2000。
- 无坐标记录的历史或外部结果给出明确操作：声明源轨道坐标系后重新运行。此操作不会隐式转换坐标。
- 报告的遥测字段从通用 `status` 改为 `telemetry_status`，显示为“遥测比较”，区分未导入数据、尚未生成比较结果、已生成比较结果。
- 生成比较结果不等于通过物理验证；原有逐节点误差和验证判据不变。
- PDF 和 Markdown 共用中英文元数据说明；CSV 保留机器可读代码。
- 未修改节点面积、热导、辐射参数、轨道数值或温度求解算法。

旧版已独立备份。Windows 应用包继续使用 MATLAB Runtime R2021b，无需另装 MATLAB。
