# v1.2.8 - 原生 MATLAB 科研图形

- 报告与论文共用 MATLAB 图形样式及绘制函数，不新增 Python 或 R 运行依赖。
- 统一中英文字体、色盲友好配色、线型、弱网格、图外图例和物理图幅。
- 多节点曲线按每组至多六条分面，保持相同纵轴范围；不改变温度或热流数值。
- 热容、功耗、光学参数和面积采用共享节点顺序的并列图，保留零值。
- 导热连接改用带数值的对称矩阵，保留节点编号、名称和热导单位；空白格表示无直接连接。组合图中矩阵占满上排，下排展示温差曲线。
- 图形导出包含 300 dpi PNG 和矢量 PDF；自动生成 publication_* 组合图及源数据 MAT。
- 论文可直接使用软件导出的组合图，无需拼接截图或另写绘图实现。
- 遥测散点和残差图保留全部已评分样本，取消旧版最多 1200 点的绘图抽样。
- 中文 β 角轴名统一为轨道 β 角。
- 计算模型、积分器和验收阈值未改变。修改前已保存 v1.2.7 源码快照。
