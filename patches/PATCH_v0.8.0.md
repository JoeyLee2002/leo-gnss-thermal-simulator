# v0.8.0 三维几何输入与面片环境预览

日期：2026-09-14

## 新增

- 支持导入 STL 和 OBJ 三角表面网格；OBJ 多边形自动三角化。
- 计算并保存顶点、面片、面积、法向、包围盒、边界边和闭合状态。
- 支持 m、mm、cm 和 in 输入单位，并统一转换为米。
- 在 GUI 新增“三维几何”配置页，提供可旋转三维预览。
- 支持按面片显示几何、太阳直射功率和总外部辐射功率。
- 三维几何进入仿真任务、项目保存、结果导出和输入指纹。
- 增加网格读取、面片热流和任务集成回归测试。

## 重要边界

本版本的网格功能是面片级环境热流预览和几何资产管理，不是三维温度场求解器。当前正式温度
结果仍由原有集中参数热网络生成；尚未启用面片自遮挡、面片间红外辐射、三维固体导热和网格到
热节点的自动耦合。界面对此作出明确提示，不将预览结果标记为三维热仿真结果。

## 兼容性

- 没有导入网格时，原有集中参数场景、扫描、遥测和标定工作流保持不变。
- 旧项目没有几何字段时按无网格项目打开。
- 修改网格后，已有结果会被标记为过期，需重新检查或运行任务。

## 验证

- 全部 MATLAB 回归测试通过：当前共 181 项，0 失败，0 未完成。
- 新增 ASCII OBJ 三角面、四边形三角化、面片热流和非法法向测试。
