## 跟着做

1. 启动软件，先完成内置“第一次仿真”。
2. 解压配套的 `教学案例与报告.zip`。MAT 项目可通过“打开项目”载入。
3. 本教程各案例用于流程学习。实际卫星任务需换成自己的模型参数、网格和有来源的数据。
4. 在新目录运行，不覆盖已有案例。优先检查该目录下 `report/thermal_report_zh.pdf`。
5. 三维边界设置、遥测列映射、设备标定范围必须明确提供，不能省略后依赖程序猜测。

## 录制中发现的问题

- 三维统一任务成功后，三维页可能仍显示旧结果过期。视频保留了实际提示；本次新结果和热流闭合差在任务 PDF 与 `pipeline_run.mat` 中。没有通过改截图隐藏这个问题。
- 旧的公开 `app.exportResults` 接口不能直接导出仅保存在 `lastPipelineRun` 中的统一任务，返回“没有结果”。统一任务本身已生成报告和审计数据，本教程使用这些自动输出；不能据此声称旧接口也通过了检查。
- 标定演示由公开 MATLAB 接口执行，展示真实 GUI 状态和输出。未把未通过验收的合成标定强行接入后续正式流水线。

这些是当前 v1.2.0 的边界，本次交付是教学视频，不是修复后的新软件发布。
