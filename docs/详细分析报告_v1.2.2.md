# v1.2.2 详细热分析报告

v1.2.3 结果审查更新：跨轨相位方向不一致时，不再挑选正时延周期来汇总。报告从原始时序重算峰值相位，修复光照事件计数、预热配置标注和缺失值工况错配。能量 CSV 与图表都从分析起点重新计零。详细修订见 `PATCH_v1.2.3.md`（源码位于 patches 目录，独立版位于解压目录）。

## 怎样生成

使用新版程序打开模板或项目，选择语言及可选任务，执行完整任务。完成后打开本次结果目录中的 `thermal_report_zh.pdf` 或 `thermal_report_en.pdf`。也可以将已有、未过期的结果导出到新目录。旧 PDF 不会被自动改写。

标准节点任务新增十一项分析：时间覆盖、热容与功耗、导热连接、光学参数、轨道光照、环境吸热、节点温度、温差与导热负荷、能量闭合、热滞后可辨识性、初温与漂移。另附全节点统计。勾选并完成的扫描、三维、标定和遥测阶段继续自动加入报告。

## 怎样判读

- 温度极值和完整峰峰差来自全部保留历元；原有分位跨度不是同一个指标。均值按时间加权。
- 图中节点编号对应附表。时序图最多显示温度极差最大的十二个节点，CSV 保留全部节点；热导矩阵最多展示前三十个节点。
- 累计储能与积分净热量均从分析起点重新计零。小闭合差说明数值记账一致，不说明真实卫星参数准确。
- `NaN` 时延表示未定义，通常需要更长数据、可辨识峰值或有效光照变化，不能解释为零滞后。
- 固定预热圈数不等于完成周期稳态检验；不同相位的初末温差也不是稳态误差。
- 没有设备允许温度范围或独立实测数据时，报告不判定工程合格或物理验证通过。
- 只有遥测导入、没有热仿真结果的任务不会为了凑页数生成不存在的节点分析。

## 复核文件

同目录保存 `thermal_node_statistics.csv`、各分析图、Markdown、`thermal_report_data.mat` 和 `thermal_manifest.json`。清单记录实际 PDF 页数与章节；MAT 保存准确的源结果，便于复算。章节和页数随任务内容变化。

## 更新说明

源代码用户运行更新后的程序即可。独立版用户必须使用新版 `LEOTherm.exe`，旧程序不会因替换 README 而更新。小独立版仍使用免费 Runtime R2021b，无需安装 MATLAB；它不是包含 Runtime 的完整免安装包。不要直接替换旧免安装包中受完整性校验的文件。
