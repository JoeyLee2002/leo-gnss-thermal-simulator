# v1.5 原生 MATLAB 图形导出

软件报告和论文图形共用原生 MATLAB 绘图函数，温度、热流和热导矩阵来自当前任务数据。中文和英文只改变文字，不改变数值。

运行完成后，在 `report` 目录查看 `publication_*` 分组及对应源数据 MAT。图形提供 PNG 和矢量 PDF；文件基础名均为英文，语言后缀为 `_zh` 或 `_en`。导热关系使用具名节点矩阵和实际热导数值，不采用交叉连线。单一时延值用正文说明，不单独生成信息稀少的单点图。

生成图表和 PDF 时，进度窗口显示当前分析部分；可请求停止，在当前导出返回后的检查点生效。完整交付以任务状态 `complete` 为准。已有报告不会被自动改写。
