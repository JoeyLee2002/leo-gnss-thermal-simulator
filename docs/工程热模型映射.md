# 工程热模型到现有网络的显式映射

`leotherm.model.previewNetworkMapping`、`applyNetworkMapping` 和
`validateNetworkMapping` 是 `leotherm.thermal_model.v1` 交换模型到现有 lumped
`network` 求解器输入之间的窄适配层。它们只新建一个网络副本，不修改传入的网络、
求解器或 GUI。

## 显式映射契约

映射必须是标量结构，且 `entries` 为结构数组。每一项都同时声明交换节点 id 和
一个网络目标：

```matlab
mapping.schema = 'leotherm.thermal_model_mapping.v1';
mapping.allowedFields = {'capacityJK','internalPowerW'};
mapping.entries = struct(...
    'exchangeNodeId', {'x1','x2'}, ...
    'networkNodeIndex', {1, []}, ...
    'networkNodeName', {'', 'gnss_rf_frontend'});
```

`networkNodeIndex` 和 `networkNodeName` 不能同时声明。名称只有在映射项明确给出
`networkNodeName` 时才会使用；程序不会根据交换节点 `id`、`name`、位置或字段名称
进行猜测。交换节点和网络节点必须是一一对应关系，重复目标、未知目标、未知交换 id
和缺失字段均报告为冲突。

允许写入的字段只有：

`capacityJK`、`internalPowerW`、`projectedAreaM2`、`radiatingAreaM2`、
`solarAbsorptivity`、`irEmissivity`、`initialTemperatureK`。

顶层 `allowedFields` 是默认白名单；单个 entry 可以用 `fields` 或 `allowedFields`
缩小白名单。单位必须已经是 v1 的 SI 单位（J/K、W、m²、K），不会自动把 mm、摄氏度
或其它单位换算。所有值必须是有限实数标量，并满足网络验证器的物理范围。

## 预览、确认和应用

```matlab
preview = leotherm.model.previewNetworkMapping(model, network, mapping);
disp(preview.changedFields)       % oldValue/newValue/source
disp(preview.conflicts)
```

预览默认是只读的，包含 `changedFields`、未映射交换节点、冲突、模型/映射 SHA-256
指纹、来源和一次性确认 token。即使没有冲突，也必须显式确认后才能生成新网络：

```matlab
[newNetwork, result] = leotherm.model.applyNetworkMapping(...
    model, network, mapping, 'ConfirmationToken', preview.confirmationToken);
% 或在已由上游流程审阅后：
[newNetwork, result] = leotherm.model.applyNetworkMapping(...
    model, network, mapping, 'AllowApply', true);
```

`applyNetworkMapping` 会重新验证结果网络，并在 `newNetwork.thermalModelMappingProvenance`
及 `newNetwork.provenance.thermalModelMapping` 中保留来源、模型/映射/预览指纹、修改字段、
未映射节点和确认方式。冲突、无效物理值或缺失确认都会拒绝应用，绝不会静默覆盖。

## GUI 闭环

GUI“工程热模型”页在导入 MAT/JSON 后显示 schema、模型 ID、单位、来源、节点/材料数量和校验状态。
随后可载入显式映射文件，或生成只包含交换节点 ID 的最小模板；模板不会替用户填写网络目标。
点击“预览映射”后，摘要会列出 changed fields、未映射节点、冲突以及模型/映射/预览指纹。
只有在确认对话框中明确选择“应用”才会调用带 confirmation token 的 apply；应用后新网络会重新接回当前仿真任务，
已有结果标记为需重新运行。 “回滚网络”可恢复导入工程热模型前保存的网络。

导入、映射校验和预览失败均不会替换当前模型或网络。GUI 同样禁止按名称猜测、自动插值和自动补齐；中英文界面
提供相同的按钮和保护逻辑。

## 边界

此适配层不创建网络节点、不推断接触或边界、不写入导热矩阵、不合并部件、不插值几何，
也不把 `materials` 或 `components` 自动折算成热参数。工程人员应先通过
`leotherm.io.validateThermalModel` 验证交换文件，再审阅预览结果，最后将新网络交给现有
求解器和其常规 `leotherm.validateNetwork` 检查。
