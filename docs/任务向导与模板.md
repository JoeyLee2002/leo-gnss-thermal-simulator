# 任务向导与 JSON 模板

## 零基础使用

1. 在 MATLAB 中运行 `launch_gui`。
2. 在“快速开始”页点击“任务向导”。
3. 选择“第一次仿真”“热滞后分析”“SATMO风格基准”或“遥测验证”。
4. 只修改任务名称、仿真时长和时间步长。
5. 配置检查通过后点击“立即运行”。

遥测模板会继续要求选择 CSV，并执行列映射和数据预检。软件不会自动补齐缺测值、
插值、猜测单位或伪造物理验证结论。

## 修改模板

复制 `templates/` 下最接近目标的 JSON 文件，然后修改副本。常用字段：

```json
{
  "schema": "leotherm.simulation_template.v1",
  "templateVersion": "1.0.0",
  "engineApi": "1",
  "id": "my_task",
  "nameZh": "我的任务",
  "nameEn": "My task",
  "descriptionZh": "一个自定义低轨热仿真任务。",
  "descriptionEn": "A custom LEO thermal simulation task.",
  "mode": "scenario",
  "networkPreset": "default",
  "scenario": {
    "name": "my_first_task",
    "durationS": 86400,
    "timeStepS": 60,
    "orbit": {
      "altitudeM": 600000,
      "inclinationDeg": 97.6,
      "raanDeg": 20
    }
  }
}
```

不需要重复写出整个场景。模板只覆盖列出的字段，其余字段来自经过验证的默认场景。
`networkPreset` 当前支持 `default`、`satmo`、`symmetric` 和 `current`。

## 可移植性

模板本身是 UTF-8 JSON，不允许函数句柄或任意 MATLAB 代码。保存工作区项目时，软件同时保存：

- 模板 ID；
- 模板源路径；
- 当次使用的完整模板快照。

因此源模板移动或以后被修改时，旧项目仍能追溯当时使用的模板内容。

## 兼容性

模板必须声明 `templateVersion` 和 `engineApi`。当前引擎 API 为 `1`。不兼容的模板、
未知热网络预设、非法轨道参数和不完整场景会在改变工作区前被拒绝。
