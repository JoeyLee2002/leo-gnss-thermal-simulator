# v0.6.0 仿真任务工作台说明

## 核心流程

软件现在围绕一个仿真任务工作：

`配置任务 → 检查配置 → 运行仿真 → 查看结果`

主界面只有“仿真”和“结果与导出”两个区域。仿真页上方的任务摘要始终显示当前
场景、热网络、节点数、遥测、标定、求解设置和结果状态。

## 使用步骤

1. 在单场景页设置日期、UTC 时刻、轨道、姿态和环境。
2. 在热网络页选择或编辑热节点、热容、导热和设备角色。
3. 如需使用遥测，在遥测页导入数据、设置映射并执行数据预检。
4. 如需标定，在设备标定页准备设备和日期，设置参数约束后执行标定。
5. 回到仿真任务摘要，点击“检查仿真配置”。
6. 检查通过后点击“运行仿真”或“运行参数扫描”。
7. 点击“查看结果”进入结果与导出区域。

各配置页仍可直接使用，但它们都服务于同一个仿真任务。修改配置后，旧结果会
显示为过期，必须重新运行。

## 数据和结果原则

遥测、模型和标定结果都属于仿真任务的输入或准备过程。每次运行使用冻结的配置快照；
项目保存、结果过期标记和无插值数据规则继续有效。
