## 如何理解

这表明完整 Runtime 可以随当前工作台搬迁运行，不需要由终端用户运行 Runtime 安装器。启动器没有下载安装动作、注册表写入或永久 PATH 配置，首次交互运行的 Runtime 许可确认由用户自己完成。

自动 smoke 由已具有 Runtime 使用权的开发者执行，没有替用户生成许可确认记录。启动器的小文件夹测试使用假 Runtime 和探针程序，仅检查启动器行为；上面两次真实 smoke 才使用完整 Runtime 和生产工作台。
