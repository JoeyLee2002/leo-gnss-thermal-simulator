# LEOTherm v1.2.10 使用教程

## 复现论文

快速开始 → 复现论文：参考任务与36工况 → 复现论文并生成报告 → 选择保存位置 → 等待报告打开。

完整步骤、固定参数、源码及 Runtime 命令见[论文结果复现](论文结果复现_v1.2.10.md)。这是重算，不是打开旧CSV。软件创建新的结果子目录，保留原始输入、模型和各工况温度。

## 自己的仿真任务

1. 在快速开始选择首次仿真，或用任务向导加载 JSON 模板；也可打开已有项目。
2. 在仿真页设置轨道、姿态、热网络及分析时段。
3. 按需选择参数扫描、三维分析、遥测对比、设备标定。未选择的阶段跳过；选择的阶段需要对应输入。
4. 检查任务，修正提示的字段后运行；选择一个保存位置。
5. 在结果与导出打开报告。章节、图表和总结来自本次实际运行；同时保留 CSV、MAT、运行记录和原生 MATLAB 科研图形。

## 指标

温度百分位差 P95-P5 与温度极差（最大减最小）分开显示。等效热导单位 W/K，材料热导率单位 W/(m K)。峰间时延、轨道基频相位时延和热时间常数不能互换。见[术语与指标](术语与指标.md)。

## 旧项目

内置六个项目已更新到本版本。用户项目仍可读取，重新运行后生成新版报告；旧结果与旧 PDF 不自动改写。机器指标键保留兼容别名，CSV增加中英文名称和定义。重复的旧六工况论文示例已删除，统一使用论文复现入口。
