# LEO GNSS 热滞后仿真器软件验收报告

验收版本：0.2.1  
验收日期：2026-09-02  
验收环境：Windows，MATLAB R2021b，纯 MATLAB 运行路径

## 1. 验收结论

版本0.2.1已经达到“可重复科研软件”的发布条件：标准场景、外部轨道、通用热网络、
批量扫描、随机不确定性、结果导出和绘图均可用；已确认的静默输入漏洞均已修复。

它目前还不能称为任务级工程热分析软件或完全成熟的桌面产品。主要差距不是核心
程序稳定性，而是缺少真实卫星标定、独立高保真数值对照、通用批处理断点续跑、
安装包和持续集成。

## 3. 本次发现并修复的问题

1. 外部轨道可传入单个历元时间配合多行状态，计算阶段未立即拒绝。
2. 全零或非正交姿态矩阵会被当成有效本体系，导致错误热流仍能继续传播。
3. 非有限表面法向和错误长度的码偏差系数未在网络验证阶段发现。
4. 通用节点网络能够计算，但绘图函数硬编码GNSS节点名而失败。
5. 零步长先触发超大数组申请，负时长返回底层索引错误，提示不可操作。
6. 没有完整案例的扫描仍会导出一张空白但外观正常的图。
7. 公共物理扫描中一个案例失败会中止整批任务，且失败诊断不统一。
8. 中文说明书仍显示旧版0.1.0，容易造成结果版本记录错误。
9. 无交互宿主关闭标准输出流时，进度文字可能中断论文批任务。

任务级温度预报或未经标定的真实码偏差定量结论。

## 5. 剩余风险与下一步

优先级P1：

- 用相同几何、表面参数和时间步长完成SATMO或另一独立求解器的数值对照。
- 增加外部轨道单位/坐标系元数据；程序无法仅从数值自动识别ECI与ECEF混用。
- 把论文套件已有的检查点机制下沉到两个公共扫描API，并支持进度和取消。

优先级P2：

- 提供配置文件模板和MATLAB App或引导式场景构建器。
- 生成MATLAB Toolbox安装包并建立自动化持续集成。
- 增加性能剖析、覆盖率报告和可选并行后端；串行路径继续保持无工具箱依赖。
- 将软件诊断图与论文投稿图分离，投稿图继续由独立的规范绘图流程生成。
