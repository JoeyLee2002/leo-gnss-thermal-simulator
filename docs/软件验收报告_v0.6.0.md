# v0.6.0 仿真任务工作台验收记录

日期：2026-09-14。

验收目标是让用户围绕一个仿真任务完成配置、检查、运行和结果分析，同时保留旧版
内部面板接口和已有实验能力。

当前版本的自动化验收证据写入 `results/verification_v060.mat`、
`results/gui_smoke_v0_6_0/` 和 `results/usability_v0_6_0b/`。
`results/layout_check_v060.log` 记录了 1120×780 小窗口的可见控件边界检查。

标定专项的第一次运行发现任务摘要占用空间后会裁切底部提示，已将任务摘要压缩并用
轻量布局检查复核通过；完整标定专项第二次运行在 GUI 导出阶段被安全终止，未将其计入
通过统计。已有的 v0.5.1 标定专项通过记录仍保留，未被覆盖。

本版本是工作流和 GUI 状态层升级，不改变热物理方程，也不把软件验收解释为真实卫星
热真空或在轨物理验证。

v0.7.0 的任务对象验收证据另见 `results/task_core_v070.log`；它覆盖任务结构、冻结
标识、输入指纹、场景运行和扫描模式保护。
