# LEOTherm v1.2.7 使用教程

## 1. 下载与启动

在 [v1.2.7 发布页](https://github.com/JoeyLee2002/leo-gnss-thermal-simulator/releases/tag/v1.2.7) 的 Assets 中下载 `LEOTherm_1.2.7_windows.zip`。
这是 Windows 应用包，不是 GitHub 自动生成的 Source code 压缩包，也不是旧的 Runtime 免安装整包。

1. 安装免费的 MATLAB Runtime R2021b。已有兼容版本无需重装，不需要 MATLAB 许可证。
2. 完整解压应用包到可写目录，例如 `C:\LEOTherm_1.2.7`。
3. 双击 `LEOTherm.exe`。首次启动需要初始化 Runtime，等待窗口出现，不要连续重复双击。
4. 新会话默认英文，可用语言选择器切换中文；打开已有项目时会恢复项目保存的语言。

有 MATLAB 的用户可在项目根目录运行 `launch_gui('zh')`。源代码运行和独立程序运行是两种不同方式，Runtime 不能直接执行 `.m` 源码。

## 2. 完成第一次仿真

按下面这条路径做，可以得到一个完整任务目录和 PDF，而不仅是一张图。

1. 进入“快速开始 / Quick start”，点击“任务向导 / Task wizard”。
2. 选择“第一次仿真 / First simulation”模板。
3. 输入任务名 `my_first_task`，时长 `2` 小时，步长 `60` 秒。
4. 在后续选项中选择“只载入模板 / Load only”，先进入统一任务流程。
5. 进入“仿真 / Simulation”，首次运行将扫描、三维耦合、遥测对比和设备标定四项全部取消勾选。
6. 点击“检查任务 / Check task”。若提示缺项，按提示修正已选模块的配置，再检查一次。
7. 点击“运行任务 / Run task”，选择结果保存位置，等待本次任务完成。
8. 在“结果与导出 / Results and export”点击“打开本次报告 PDF / Open this run PDF”。

这条路径使用参考节点网络，不需要自行准备网格或遥测。预热阶段仍会执行；上面设置的 2 小时是分析时长，不是软件预计运行时间。
模板默认固定预热 1 圈，用于形成分析窗口开始前的温度状态；这不是“周期稳态已收敛”的自动证明。

快速开始中的“使用模板并开始仿真 / Use template and run”是另一条快捷路径。
若只做了单模块计算，导出按钮可能显示“生成分析报告 PDF / Generate analysis PDF”。完整任务建议按上述“检查任务 → 运行任务”路径执行。

## 3. 只修改模板中的少量参数

复制 `templates/01_first_simulation.json` 后编辑自己的副本。
初次只修改 `scenario.name`、`scenario.durationS`、`scenario.timeStepS`。

| 字段 | 单位或含义 | 示例 |
| --- | --- | --- |
| `scenario.name` | 任务名称 | `my_first_task` |
| `scenario.durationS` | 秒 | `7200` 表示 2 小时 |
| `scenario.timeStepS` | 秒 | `60` |
| `scenario.warmupOrbits` | 预热轨道圈数 | `1` |

JSON 中的时长是秒，向导中的时长是小时，不要混用。
保留 `schema`、`templateVersion`、`engineApi` 等声明；在向导中选择其他 JSON 模板来载入副本。
模板不支持任意 MATLAB 代码执行。需要定制热网络时，先配置节点、材料和连接，再保存项目。

## 4. 按需要启用附加任务

基础节点热仿真始终运行。每次先准备对应输入，再勾选模块、检查并运行一个新任务。

| 可选阶段 | 运行前准备 | 报告检查重点 |
| --- | --- | --- |
| 参数扫描 | 扫描模式及高度、β角或日期、倾角、RAAN 列表 | 工况数量、参数变化和温度/响应变化；一个工况不能构成趋势 |
| 三维耦合 | 表面网格、体网格、材料及耦合边界 | 网格温度、热流映射和守恒；当前表面到体的驱动为单向耦合 |
| 遥测对比 | 时间、单位、节点映射和覆盖范围明确的数据 | 实际匹配样本、RMSE、残差和数据独立性 |
| 设备标定 | 标称参数、允许范围、训练/验证/测试划分 | 参数改变量，以及训练与留出数据各自的误差变化 |

不使用的阶段不勾选。仅导入遥测文件不等于已经完成比较；演示用合成遥测也不是在轨验证。
标定和遥测对比使用同一数据源时，下游比较使用保留的测试日；重叠数据等问题由预检处理。
软件不自动插值补齐有问题的数据，输入应满足声明的时间覆盖和匹配要求。

## 5. 阅读新版报告

按“任务输入 → 热输入 → 温度与传热 → 响应指标 → 数值复核 → 任务总结”的顺序阅读。

- 先核对任务名称、时间窗口、步长及热网络，确认不是上一次任务的文件。
- 热输入章节说明太阳直射、反照和地球红外的吸热构成。
- 温度章节分别查看最高温、最低温、最大波动和目标部件温度，不以整星极值代替接收机温度。
- 导热章节结合连接图和实际平均净热流读方向，不能仅凭连接粗细推断传热方向。
- 周期响应章节分析轨道基频相位；逐圈峰值对齐是另一种指标，两者不能混为同一个时间。
- 网格加密比较仅在任务提供相应复算结果时出现，不会凭空增加额外步长的结果。
- 最后看“任务总结”，再回到对应图表核对数值。可选阶段只有实际执行后才加入报告分析。

v1.2.7 删除了开头的“关键发现与解读”，不再显示说明性页脚，页码居中；正文两端对齐、末行左对齐。
发布页的中英文参考报告各 19 页，但你自己的页数取决于时长、数据和已执行阶段，不要求恰好 19 页。
数值检查用于检查计算；设备工作温度是否满足要求，需要结合你设备的设计限值。

## 6. 保留结果并完成复核

完整保留任务目录，不要只留下 PDF。

| 文件 | 用途 |
| --- | --- |
| `input_snapshot.mat` | 本次输入快照 |
| `frozen_model.mat` | 本次冻结模型 |
| `pipeline_run.mat`、`pipeline_status.json` | 运行结果与阶段状态 |
| `report/thermal_report_zh.pdf` 或 `_en.pdf` | 按任务语言生成的报告 |
| `report/thermal_report_data.mat` | 报告所用数据包 |
| `report/thermal_interpretation_evidence.csv` | 分析推导指标、单位和来源 |
| `report/thermal_node_statistics.csv` | 各节点温度统计 |

验收顺序：检查任务完成 → 核对配置与图表 → 阅读数值检查 → 检查已选模块结果 → 保存整个目录。
修改配置或升级软件后，请运行新任务并导出到新目录。打开已有任务的 PDF 不会自动重新计算或改写旧报告。

## 7. 常见情况

| 情况 | 处理 |
| --- | --- |
| 启动后暂时没出现窗口 | 等待首次 Runtime 初始化；确认完整解压并安装 R2021b Runtime |
| 报告仍是旧版样式 | 确认启动的是 1.2.7 程序，并打开新任务的报告，而非旧目录 |
| 没有扫描、遥测或标定分析 | 检查本次是否勾选且真正完成该阶段 |
| 找不到“生成分析报告 PDF”按钮 | 完整流水线已生成报告时，按钮会变为“打开本次报告 PDF” |
| 修改配置后旧结果不更新 | 重新检查并运行；旧任务保留原来的模型和结果 |
| 中文视频中的布局与当前稍有不同 | 视频为 v1.2.0/1.2.1 录制，新版操作与报告规则以本教程为准 |

仓库保留旧视频供学习流程。本次更新的是 v1.2.7 双语文字教程及报告示例，没有把旧视频标成重新录制的新视频。
