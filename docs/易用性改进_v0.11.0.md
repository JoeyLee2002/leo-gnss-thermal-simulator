# v0.11.0 快速开始工作区说明

v0.11.0 将“快速开始”作为图形界面的默认入口。用户先选择任务目标，再决定是否
直接运行标准模板或进入完整的高级仿真设置。原有仿真、扫描、热网络、三维几何、
遥测、标定和结果功能均保留。

## 三个任务目标

- 第一次仿真：600 km、对地定向、2 小时、关闭周期收敛，适合确认软件流程。
- 热滞后分析：默认参考场景、24 小时、周期热状态收敛，适合查看入影和热滞后指标。
- 遥测验证：进入遥测与验证页，导入数据并完成映射预检；没有数据时不会伪造验证结果。

## 用户原则

新手只需要先回答“我要做什么”。标准模板不会修改已保存的项目文件；如果当前工作区有
未保存修改，运行模板前会明确提示。专业用户使用“高级仿真设置”进入原有完整工作区。

结果页继续显示输入是否一致、结果是否过期、是否使用参考网络以及半仿真观测模型的
解释边界。快速开始不会改变轨道传播、热流方程或热网络求解器。
