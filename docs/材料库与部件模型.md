# 材料库与部件模型

本扩展位于 `src/+leotherm`，不改变现有求解器、`ThermalSimulatorApp.m` 或 `+model` 目录。所有内置材料均为工程参考值（`isReferenceValue=true`、`provenance='reference_only'`），不是任何卫星的实测数据。

## 材料库

```matlab
ids = leotherm.materialLibrary('list');
al = leotherm.materialLibrary('get','aluminum_6061');
v = leotherm.materialLibrary('evaluate', al, 293.15);
```

材料结构至少包含 `id`、`name`、`kind`、`source`、`confidence` 和 `uncertainty`。`kind='constant'` 时提供正的 `conductivityWmK`、`densityKgM3`、`specificHeatJkgK`；`kind='temperature_dependent'` 时可提供相应的 `...Fcn` 函数句柄（输入 Kelvin 温度），或正值曲线数组。可选的 `solarAbsorptivity` 与 `irEmissivity` 必须在 `[0,1]`。来源不得为空；不确定度必须为有限非负数，置信度可用文字或 `[0,1]` 数值。

注册/校验自定义材料：

```matlab
m = leotherm.materialLibrary('register', myMaterial);
```

## 等效部件与节点映射

部件需要 `id`、`name`、`source`、`confidence`、`uncertainty`，以及 `nodeIndex` 或 `nodeName`。热参数可直接给 `capacityJK`，或给 `massKg` 加材料（自动按材料比热计算等效热容）。`contactConductanceWK`、功率和面积不能为负；光学属性仍受 `[0,1]` 约束。

```matlab
c = struct('id','rf_box','name','RF box', ...
    'nodeName','gnss_rf_frontend','material','aluminum_6061', ...
    'massKg',2,'projectedAreaM2',0.1,'radiatingAreaM2',0.1, ...
    'source','supplier datasheet, rev A','confidence','medium', ...
    'uncertainty',struct('massKg',0.05));
c = leotherm.componentModel(c, leotherm.defaultReceiverNetwork);
```

映射后返回 `nodeIndex`、`nodeName`、`capacityJK` 及光学/等效参数，可由上层代码写入已有网络；本模块不会隐式修改网络。非法节点、负参数、越界光学量、缺失来源和无效不确定度均会抛出 `leotherm:InvalidMaterial` 或 `leotherm:InvalidComponent`。

## 置信度与不确定度约定

`confidence` 描述证据等级，不等同于统计置信区间；`uncertainty` 保存各参数的相对或绝对不确定度（字段名由用户定义，但数值必须非负）。使用任务实测或供应商数据时，应在 `source` 中填写可追溯文档、版本和日期，并将 `isReferenceValue` 设为 `false`。
