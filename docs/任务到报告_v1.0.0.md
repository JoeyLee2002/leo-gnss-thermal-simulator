# 从任务到分析报告（v1.0.0）

## 第一次使用

1. 在 MATLAB 命令窗口执行：

   ```matlab
   cd('解压后的项目目录')
   launch_gui
   ```

2. 在“快速开始”选择“第一次仿真”，点击“使用模板并开始仿真”。也可以点
   “任务向导”，选择 JSON 模板，只填写任务名、时长和步长。
3. 运行结束后打开“结果与导出”，先查看本次结论和结果状态。
4. 点击“生成分析报告 PDF”，选择保存位置。完成后可直接打开 PDF。

软件会创建一个带时间戳的结果目录。主要交付是
`report/thermal_report_zh.pdf`（英文界面为 `_en.pdf`）。同目录保留
`thermal_manifest.json`、Markdown、CSV、MAT 和图像；场景、扫描、面片、
体网格等原始结果在各自子目录中。

## 报告如何变化

- 单场景：给出 β 角、入影比例、节点温度跨度、半仿真码偏差、时延和时序图。
- 参数扫描：列出有效与失败工况数，并在可绘制时加入扫描图。
- 表面/体网格：列出网格、材料、温度范围和可用的能量诊断。
- 遥测比较：列出有效样本数、RMSE、用户阈值评价和独立性说明。
- 组合任务：各模块在同一 PDF 中出现，缺失证据会明确标注。

报告末页逐项写明数值是否有效、已有结果是否与当前输入一致、遥测比较是否执行，
并说明哪些结论尚不能称为物理验证。若修改了输入，报告会把旧结果标成过期；
重新运行后再出正式报告。

## 验收一次结果

检查 PDF 的任务名称、日期、输入参数和图表；确认“验收与解释边界”页没有
“已过期，需要重新运行”。使用真实遥测时，再核对样本数、RMSE 和独立性描述。
默认参考网络没有经过特定卫星标定；能导出 PDF 不代表实测物理检验已通过。

高级配置仍在“仿真”页。复制 `templates/` 内最接近任务的 JSON 后只改需要的字段，
可从任务向导载入；无需在 GUI 中逐项填写全部参数。
