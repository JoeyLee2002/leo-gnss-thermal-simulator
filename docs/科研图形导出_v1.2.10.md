# v1.2.10 科研图形导出

报告图、论文图共用原生 MATLAB 绘图函数。报告目录同时输出 PNG 和矢量 PDF。`publication_*` 图组与对应 `_source.mat` 文件保留原始图表数组。

论文36工况图为 `publication_paper_study_zh.png` / `publication_paper_study_en.png`：上排温度百分位差 P95-P5，下排轨道基频相位时延；三列高度一致，三种等效热导使用共同图例。论文直接嵌入这些导出图，不另用其他绘图工具重新拟合或平滑数据。

报告名称和指标定义见 `thermal_metric_definitions.csv`；时间序列见论文任务目录的 `open_data`。图中连线用于连接实际计算工况，不表示已计算中间工况。
