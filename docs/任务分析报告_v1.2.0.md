# v1.2.0 任务分析报告

可以先打开[五页中文样例](../examples/reports/参考网络_多工况扫描_报告样例_v1.2.0.pdf)。它由参考热网络、2 小时仿真、500/600 km 与 0/15/30 度目标β角的六个工况生成；没有预热，不代表真实卫星验证。

任务运行完成后，打开该任务目录下的 `report/thermal_report_zh.pdf`（英文任务为 `thermal_report_en.pdf`）。同目录保留 Markdown、原始 MAT、CSV、清单和各页图像，可用于复核。

报告只分析实际完成的阶段：

| 阶段 | 进入报告的内容 |
| --- | --- |
| 基础节点仿真 | β角、入影、节点温度、时延及设定灵敏度下的码偏差；日照/热流/温度时序图 |
| 参数扫描 | 完成工况数、β角及响应范围、扫描图；单工况明确不推断趋势或最优值 |
| 三维几何 | 表面与体网格温度范围、热流映射闭合差、温度时序图；注明单向耦合边界 |
| 遥测对比 | 精确历元匹配后的样本数、温度 RMSE、观测与仿真散点及残差图；标注数据独立性 |
| 设备标定 | 训练、验证、测试分组的标称/标定 RMSE 及对比图；不把训练误差当独立验证 |

未勾选的阶段不生成分析页，验收页明确标“跳过”。所给默认网络是研究示例；数值验收通过不等于真实卫星的物理验证。合成遥测不能作为在轨验证。图表中的时延若未定义，不应解释为零。
