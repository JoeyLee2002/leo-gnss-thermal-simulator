# v0.5.0 GUI 重组验收记录

日期：2026-09-14。版本目标：把软件从“模块集合”重组为“仿真工作台”。

## 验收标准

- 顶层只有“仿真”和“结果与导出”。
- 仿真配置页仍可访问单场景、扫描、热网络、遥测和标定。
- 低频操作不再平铺为主按钮。
- 语言切换、项目恢复、结果过期标记和旧自动化接口不被破坏。

验收证据目录为 `results/gui_smoke_v0_5_0/`、`results/usability_v0_5_0/` 和
`results/device_calibration_gui_v0_5_0/`。完整自动测试结果写入
`results/verification_v0_5_0.mat`。

本版本不改变数值模型，不将界面验收解释为真实卫星物理验证。
