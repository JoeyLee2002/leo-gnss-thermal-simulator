# LEOTherm v1.5: Windows Application and Illustrated Manuals

## Download and Start

Download **LEOTherm_1.5_windows_release_illustrated.zip**, extract the entire archive, and open
`START_HERE.html`. Launch `LEOTherm.exe` after installing free **MATLAB Runtime R2021b**.
The application does not require a MATLAB licence; Runtime is installed separately.

下载图解发行包，完整解压后打开 `START_HERE.html`，再启动 `LEOTherm.exe`。
需要另行安装免费的 MATLAB Runtime R2021b，无需购买 MATLAB。

## What's Included

- Independent page-local runs, plus a separate complete-task/report action with optional sweep,
  3-D coupling, telemetry comparison and device calibration.
- Bilingual progress and cooperative stopping, ASCII output names, native-dialog window recovery,
  hidden report plotting, and on-demand loading of advanced views.
- Chinese and English illustrated user manuals: **13 annotated figures each**, in offline HTML,
  Markdown and PDF (Chinese PDF: 15 pages; English: 20 pages).
- Chinese and English paper-reproduction guides: **4 figures each** (Chinese PDF: 8 pages; English:
  11 pages), covering the entry point, progress, data files and numerical checks.
- Small example meshes and an engineering-model JSON; existing v1.2.10 videos retain their version
  labels. Current run-button instructions are in the illustrated manuals.

## Reproduce the Paper

From the application directory in PowerShell, choose a **new, nonexistent** task directory:

```powershell
.\LEOTherm.exe --paper-study "C:\LEOThermResults\paper_run_01" both
```

Or use Quick start > Paper: reference task and 36 cases > Reproduce paper and report.
The GUI selects an existing parent folder and creates a new child. GUI reports follow the selected
language; `both` on the command line produces both report languages.

The study contains one reference task, 36 factorial cases and three refinements: **40 solve jobs**.
Require final `status=complete`, 36 result rows, the four protocol checks and the selected-language
PDFs. Saved partial results after stopping are labelled `cancelled`, not complete.
