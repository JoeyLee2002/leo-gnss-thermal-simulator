# 三步快速上手（v0.17.1）

适用环境：MATLAB R2021b 或更新版本，需图形桌面。下面的第一次仿真使用参考热网络，
结果用于学习软件流程，不代表某颗卫星的实测温度。

## 1. 打开

在 MATLAB 命令窗口输入：

```matlab
cd('H:\paper\leo-gnss-thermal-simulator')
launch_gui
```

如果项目以后换盘符，将 `cd` 中的路径换成实际项目目录。

## 2. 运行

在“快速开始”页点击“任务向导”，选择“第一次仿真”。保留默认任务名、2 小时和
60 秒步长，点击确定，再点击“立即运行”。这一步通常不需要改其他参数。

## 3. 看结果

点击顶部“结果与导出”。先看结论文字是否显示单场景结果与当前输入一致，再看
温度、入影和热滞后指标。需要留存时点击“导出当前结果”，选择一个空目录。
以后可以从“打开项目”继续已保存的工作区。

需要改轨道参数时，复制 `templates/01_first_simulation.json`，修改副本的 `scenario.orbit`
字段，再从任务向导选择“选择其他 JSON 模板...”。高度单位是米，角度单位是度。
模板字段拼错或版本不兼容会在运行前报错。

遥测验证需要真实 CSV 和明确的列映射；仅导入文件不等于完成物理验证。
更详细的模板字段见 [任务向导与模板](任务向导与模板.md)。
