## 1. 软件用途

本软件用于研究低轨卫星轨道与光照条件怎样形成多节点温度变化和热滞后，并进一步生成温度诱导GNSS码偏差。完整计算链为：

```text
日期、轨道高度、倾角、RAAN、姿态
                  ↓
太阳方向、β角、入影/出影、表面太阳入射角
                  ↓
太阳直射、地球反照、地球红外、内部功耗
                  ↓
卫星表面与GNSS接收机多节点瞬态温度
                  ↓
热滞后指标和半仿真温度诱导码偏差
```

软件主要支持以下实验：

1. 单个轨道场景的温度与热滞后仿真；
2. 严格控制的“轨道高度—β角”参数扫描；
3. 日期、倾角、RAAN和季节的物理几何扫描；
4. 使用外部精密轨道和姿态历史驱动热仿真；
5. 为观测域半仿真、模型失配和POD桥接实验生成热偏差真值。

本软件是研究级参数化工具，不是卫星热控鉴定软件。默认网络尚未使用KOMPSAT-5或其他特定任务的热真空试验数据标定。

## 2. 软件组成

项目主要目录如下：

```text
leo-gnss-thermal-simulator/
├─ src/+leotherm/       核心MATLAB函数
├─ examples/            可直接运行的示例
├─ tests/               自动验证测试
├─ docs/                模型、验证和使用文档
├─ results/             运行后自动生成，不纳入Git
├─ startup.m            添加项目路径
└─ run_tests.m          执行全部测试
```

默认热网络包含11个节点：

| 序号 | 节点 | 作用 |
|---:|---|---|
| 1 | `face_+X_forward` | 卫星前向表面 |
| 2 | `face_-X_aft` | 卫星后向表面 |
| 3 | `face_+Y_orbit_left` | 轨道左侧表面 |
| 4 | `face_-Y_orbit_right` | 轨道右侧表面 |
| 5 | `face_+Z_nadir` | 对地表面 |
| 6 | `face_-Z_zenith` | 天顶表面 |
| 7 | `spacecraft_structure` | 卫星主体结构 |
| 8 | `gnss_antenna` | GNSS天线 |
| 9 | `gnss_rf_frontend` | GNSS射频前端 |
| 10 | `gnss_oscillator` | 频率基准或振荡器组件 |
| 11 | `receiver_digital` | 接收机数字板 |

## 2.1 三维几何输入

在“仿真”区域打开“三维几何”页，点击“导入 STL/OBJ”，选择卫星的三角表面网格，并在导入前
选择输入单位。程序会统一换算为米，并显示顶点数、面片数、总表面积、包围盒和边界边数量。
闭合网格的边界边数量为零，但闭合并不代表网格法向方向一定正确，仍需在预览中检查方向和比例。
“外法向表面”适用于卫星外壳；若网格表示内部腔体，可切换为“内法向表面”。

三维页的显示模式包括几何、太阳直射功率、总外部辐射功率和末时刻面片温度。可用“太阳自遮挡”开关
启用逐面片质心向太阳的射线检查。点击“运行面片热仿真”
后，程序根据面片热容、发射率、外部热流、面片间视因子和深空辐射求解每个面片的温度，并可用末
时刻面片温度着色显示。结果中的 `eclipseVisibleFraction` 是地影可见率，`faceVisibleFraction` 是乘入
结构自遮挡后的逐面片可见率，二者不能混用。节点温度结果仍由集中参数热网络求解；面片求解尚未包含
三维实体导热，不能将其解释为完整三维有限元温度场。导入或删除网格后，旧结果会标记为过期。

面片结果可以通过“结果与导出”导出。导出目录中的 `surface_mesh` 包含 MAT 结果、`face_properties.csv`
（面积、法向、光学参数、热容和初温）以及 `surface_mesh_timeseries.csv`（逐面片温度、太阳功率和
可见率）。这些文件与 `surface_mesh_metadata.mat` 中的参数来源一起用于结果复核。

程序化接口 `app.setSurfaceMeshThermal(capacityJK, initialTemperatureK, conductanceWK, provenance)` 可将
每个面片的热容、初始温度和对称面片导热矩阵写入当前网格。`provenance` 用于记录参数来源；未声明时
程序仍使用参考默认值，但结果诊断会标记其来源，不能视为具体卫星标定参数。

## 3. 运行环境

### 3.1 必需软件

- Windows、Linux或macOS；
- MATLAB R2021b或更高版本；
- 不要求 Aerospace Toolbox；
- 不要求 Python、Basilisk、SATMO或SPICE作为运行依赖。

### 3.2 首次启动

在MATLAB命令窗口执行：

```matlab
cd('H:/paper/leo-gnss-thermal-simulator')
startup
```

确认核心函数可见：

```matlab
which leotherm.simulateScenario
which leotherm.defaultReceiverNetwork
```

两个命令都应返回项目 `src/+leotherm` 下的文件路径。

查看当前软件版本：

```matlab
results = leotherm.selfTest;
```

0.4.0版本包含68项自动测试，本机全部通过；其中1项使用可选下载的真实GRACE-FO数据，未下载时会跳过。无输出参数调用时会直接显示通过数；保留输出参数时可进一步检查每项测试结果。

### 3.4 启动图形工作台

在项目根目录执行：

```matlab
launch_gui
```

默认启动全中文界面。需要英文界面时执行：

界面顶部也可以随时切换“中文/English”。切换后，全部界面文字、表格、状态信息、
图题、坐标轴与图例使用同一种语言，当前场景、热网络和已有结果不会丢失。

或者在已经运行 `startup` 后执行：

```matlab
leotherm.launchApp
```

图形工作台包含单场景、参数扫描、热网络、三维几何、遥测与验证、设备标定、结果与导出七页。它与命令行接口使用
同一个求解器和校验函数，界面输入不会绕过轨道、姿态和热网络约束。完整说明见
`docs/图形界面使用说明.md`。

测试内容包括：

- 目标β角到RAAN的反解；
- 不可达β角拒绝；
- 对地姿态坐标系正交性；
- 圆锥地影与解析圆柱地影的一致性；
- 孤立导热网络能量守恒；
- 单节点辐射平衡；
- 完整11节点端到端仿真；
- 外部轨道接口；
- 场景、网络、轨道历元和姿态矩阵的非法输入拒绝；
- 通用节点网络的计算与绘图；
- 批量失败隔离、随机样本复现和版本一致性。

只有全部测试通过后，才建议批量运行参数扫描。

```matlab
plot(result.timeS / 3600, result.temperatureK(:, rfIndex));
```

### 4.2 运行高度—β角扫描

```matlab
summary = run_beta_altitude_sweep;
```

使用 `run_beta_altitude_sweep('en')` 可生成全英文图。中文和英文图的每个子图都包含
图例，图例文字与所选语言一致。

该实验默认扫描：

- 高度：400、600、800、1000 km；
- β角：−60°、−45°、−20°、0°、20°、45°、60°。

程序不是直接篡改太阳方向，而是根据日期、倾角和目标β角反求RAAN。若目标β角在当前日期和倾角下不可实现，程序会写入：

```text
accessible = false
status = inaccessible
```

不可达案例不会插值，也不会使用邻近β角替代。

输出目录：

```text
results/beta_altitude_sweep/
├─ summary.csv
├─ summary.mat
└─ beta_altitude_summary.png
```

### 4.3 运行季节、倾角与RAAN扫描

```matlab
summary = run_physical_sweep;
```

示例包含春分、夏至、秋分和冬至附近日期，并组合：

- 多个轨道高度；
- 45°、70°和97.6°倾角；
- 0°至315°的多组RAAN。

这种实验中，β角是轨道和太阳几何的输出，不能作为独立输入。它适合回答：

- 不同倾角可以覆盖怎样的β角范围；
- 季节和RAAN怎样改变入影结构；
- 同样的β角下，姿态和太阳入射角是否导致不同热响应；
- 哪些轨道条件产生更强的加热/冷却滞后。

## 5. 自定义单个场景

### 5.1 基本写法

```matlab
startup

scenario = leotherm.defaultScenario;
network = leotherm.defaultReceiverNetwork;

scenario.startEpoch = datetime(2024, 6, 21, 12, 0, 0, ...
    'TimeZone', 'UTC');
scenario.durationS = 24 * 3600;
scenario.timeStepS = 20;
scenario.warmupOrbits = 30;

scenario.orbit.altitudeM = 550e3;
scenario.orbit.inclinationDeg = 70;
scenario.orbit.raanDeg = 120;
scenario.orbit.argumentLatitudeDeg = 0;
scenario.orbit.useJ2 = true;

scenario.attitude.mode = 'nadir';
scenario.attitude.eulerOffsetDeg = [0, 0, 0];

result = leotherm.simulateScenario(scenario, network);
leotherm.writeScenario(result, 'results/my_case');
leotherm.plotScenario(result, 'results/my_case/summary.png', 'zh');
```

### 5.2 主要场景参数

| 参数 | 单位 | 含义 |
|---|---:|---|
| `startEpoch` | UTC | 主分析时段起点 |
| `durationS` | s | 输出分析时长 |
| `timeStepS` | s | 固定积分步长 |
| `warmupOrbits` | 圈 | 主分析前的热状态预热圈数 |
| `orbit.altitudeM` | m | 圆轨道高度 |
| `orbit.inclinationDeg` | ° | 轨道倾角 |
| `orbit.raanDeg` | ° | 升交点赤经 |
| `orbit.argumentLatitudeDeg` | ° | 初始纬度幅角 |
| `orbit.useJ2` | 逻辑值 | 是否加入J2长期漂移 |
| `attitude.mode` | 字符串 | 姿态模式 |
| `attitude.eulerOffsetDeg` | ° | 姿态安装偏差或控制偏差 |

### 5.3 姿态模式

支持三种模式：

```matlab
scenario.attitude.mode = 'nadir';        % +Z轴对地
scenario.attitude.mode = 'sun_pointing'; % +X轴对日
scenario.attitude.mode = 'inertial';     % 本体轴固定在ECI
```

默认对地模式的轴定义为：

- `+X`：沿轨道速度方向；
- `+Z`：指向地心；
- `+Y`：组成右手坐标系。

因此默认GNSS天线安装在 `−Z` 天顶方向。

### 5.4 环境热流开关

```matlab
scenario.environment.includeDirectSolar = true;
scenario.environment.includeAlbedo = true;
scenario.environment.includeEarthIR = true;
```

消融实验可以分别关闭：

```matlab
scenario.environment.includeAlbedo = false;
```

但关闭某个热源后必须重新完成预热过程，不能直接修改已生成温度曲线。

## 6. 设置目标β角

使用以下函数根据指定日期和倾角反求RAAN：

```matlab
epoch = datetime(2024, 3, 20, 12, 0, 0, 'TimeZone', 'UTC');
[raanDeg, accessible] = leotherm.solveRaanForBeta(epoch, 97.6, 45, 1);
```

其中：

- `45` 是目标有符号β角；
- 最后一个参数是RAAN解分支，可选1或2；
- `accessible=false` 表示当前日期和倾角不能产生该β角。

使用求得的RAAN：

```matlab
scenario = leotherm.defaultScenario;
scenario.startEpoch = epoch;
scenario.orbit.raanDeg = raanDeg;
result = leotherm.simulateScenario(scenario, leotherm.defaultReceiverNetwork);
fprintf('平均β角：%.3f°\n', result.metrics.meanBetaDeg);
```

J2漂移和太阳运动会使24 h平均β角与起始目标β角存在小差异，这是物理演化，不应强行改回目标值。

## 7. 修改多节点热网络

### 7.1 获取默认网络

```matlab
network = leotherm.defaultReceiverNetwork;
```

所有节点参数均按列向量排列，顺序必须与 `network.nodeNames` 一致。

### 7.2 修改热容和内部功耗

```matlab
rf = strcmp(network.nodeNames, 'gnss_rf_frontend');
osc = strcmp(network.nodeNames, 'gnss_oscillator');

network.capacityJK(rf) = 2200;
network.capacityJK(osc) = 450;
network.internalPowerW(rf) = 6.0;
network.internalPowerW(osc) = 1.0;

leotherm.validateNetwork(network);
```

热容越大，通常温度响应越慢；内部功耗越大，平均温度通常越高。但热滞后由整个网络共同决定，不能把单个节点的 (C/K) 直接解释为完整卫星唯一时间常数。

### 7.3 修改节点导热

导热矩阵必须满足：

- 对称；
- 对角线为0；
- 所有元素非负；
- 单位为W/K。

示例：

```matlab
rf = find(strcmp(network.nodeNames, 'gnss_rf_frontend'));
osc = find(strcmp(network.nodeNames, 'gnss_oscillator'));

network.conductanceWK(rf, osc) = 0.30;
network.conductanceWK(osc, rf) = 0.30;
leotherm.validateNetwork(network);
```

只修改单向元素会导致验证失败，因为这会破坏热量守恒。

### 7.4 修改表面光学参数

```matlab
zenith = strcmp(network.nodeNames, 'face_-Z_zenith');
network.solarAbsorptivity(zenith) = 0.40;
network.irEmissivity(zenith) = 0.85;
```

参数必须位于0到1之间。涂层老化、太阳电池覆盖比例和MLI等因素应通过独立场景或不确定性区间处理，不宜只给一个未经说明的固定值。

### 7.5 增加节点

增加节点时必须同步扩展：

```text
nodeNames
capacityJK
initialTemperatureK
internalPowerW
projectedAreaM2
radiatingAreaM2
normalBody
solarAbsorptivity
irEmissivity
conductanceWK
bias.linearMPerK
```

增加后执行：

```matlab
leotherm.validateNetwork(network)
```

建议先添加没有外部面积的内部节点，再通过导热矩阵连接到结构或相邻设备节点。

## 8. 接入外部真实轨道和姿态

### 8.1 必需输入

`leotherm.simulateTrajectory` 接收一个轨道结构体：

```matlab
trajectory.epoch        % N×1 datetime，UTC
trajectory.elapsedS     % N×1，严格递增，单位s
trajectory.positionM    % N×3，ECI位置，单位m
trajectory.velocityMps  % N×3，ECI速度，单位m/s
```

可选输入：

```matlab
trajectory.sunPositionM       % N×3，ECI太阳位置，单位m
trajectory.betaDeg            % N×1，有符号β角
trajectory.periodS            % 标称轨道周期
trajectory.raanDeg            % N×1或标量
trajectory.frameBodyAxesECI   % N×3×3，本体系各轴在ECI中的表达
```

若不提供太阳位置，程序使用内部解析太阳星历。若不提供姿态矩阵，程序使用 `scenario.attitude` 生成姿态。

### 8.2 调用示例

```matlab
scenario = leotherm.defaultScenario;
network = leotherm.defaultReceiverNetwork;

analysisMask = trajectory.elapsedS >= 0 & trajectory.elapsedS <= 86400;
result = leotherm.simulateTrajectory( ...
    trajectory, scenario, network, analysisMask);
```

外部轨道必须已经统一到ECI坐标系。本接口不会自动判断ECEF和ECI，也不会对缺测历元进行插值。存在时间倒序、重复历元或缺失轨道段时，应先剔除问题弧段。

从0.2.1开始，程序会在热积分前检查历元数、数组维数、有限值、位置速度方向以及姿态矩阵。错误输入分别返回 `leotherm:InvalidTrajectory`、`leotherm:InvalidScenario` 或 `leotherm:InvalidNetwork`，避免生成表面正常但物理含义错误的结果。

### 8.3 姿态矩阵约定

`frameBodyAxesECI(k,:,:)` 是第 `k` 个历元的3×3矩阵，每一行依次表示本体 `+X`、`+Y`、`+Z` 轴在ECI中的单位向量。

每个姿态矩阵必须满足：

```matlab
R * R' = eye(3)
det(R) = 1
```

四元数输入应先转换成上述约定，并用已知姿态案例检查主动/被动旋转和四元数分量顺序。

## 9. 输出结果说明

### 9.1 `result` 结构体

| 字段 | 内容 |
|---|---|
| `scenario` | 场景配置 |
| `network` | 节点与热参数 |
| `timeS` | 主分析时段相对时间 |
| `orbit` | 轨道、太阳和β角 |
| `frame` | 姿态矩阵历史 |
| `loads` | 各节点外部热流 |
| `temperatureK` | N×节点数温度矩阵 |
| `codeBiasM` | 半仿真温度诱导码偏差 |
| `metrics` | 汇总指标 |

### 9.2 热流字段

```matlab
result.loads.visibleFraction  % 太阳可见比例，0至1
result.loads.directSolarW     % 每个节点太阳直射功率
result.loads.albedoW          % 每个节点反照功率
result.loads.earthIRW         % 每个节点地球红外功率
result.loads.totalExternalW   % 三种外部热流之和
result.loads.sunIncidence     % 各节点太阳入射余弦
result.loads.earthIncidence   % 各节点地球入射余弦
```

### 9.3 主要指标

| 指标 | 含义 |
|---|---|
| `meanBetaDeg` | 主分析时段平均有符号β角 |
| `eclipseFraction` | 太阳盘非完全可见的历元比例 |
| `umbraFraction` | 完全本影历元比例 |
| `rfTemperatureSpanK` | RF温度95%−5%跨度 |
| `oscillatorTemperatureSpanK` | 振荡器温度95%−5%跨度 |
| `codeBiasSpanM` | 半仿真码偏差95%−5%跨度 |
| `forcingToRfLagS` | 总外部热流到RF温度的正时延相关峰 |
| `eclipseEntryCoolingLagS` | 入影后最强冷却速率的中位延迟 |
| `eclipseExitHeatingLagS` | 出影后最强加热速率的中位延迟 |

`forcingToRfLagS` 是描述性相关指标，不等于某个独立物理节点的唯一时间常数。多周期信号可能出现相关峰混叠，因此应同时报告入影和出影事件指标。

## 10. 温度诱导码偏差

默认码偏差由节点温度异常线性组合和RF节点二次项构成：

```matlab
network.bias.linearMPerK
network.bias.quadraticNode
network.bias.quadraticMPerK2
```

修改示例：

```matlab
network.bias.linearMPerK(:) = 0;
network.bias.linearMPerK(rf) = 0.05;
network.bias.linearMPerK(osc) = 0.10;
network.bias.quadraticMPerK2 = 0;
```

这些系数决定半仿真偏差幅值，但不改变热网络温度。论文实验应把以下两部分分开报告：

1. 物理热网络产生的节点温度和滞后；
2. 假定灵敏度映射产生的观测域码偏差。

不能用人为设置的米级码偏差反向证明真实卫星一定存在同样幅值。

## 11. 消融和敏感性实验

### 11.1 热源消融

分别运行完整模型和关闭单一热源的模型：

```matlab
fullScenario = leotherm.defaultScenario;

noAlbedo = fullScenario;
noAlbedo.environment.includeAlbedo = false;

noEarthIR = fullScenario;
noEarthIR.environment.includeEarthIR = false;

noDirect = fullScenario;
noDirect.environment.includeDirectSolar = false;
```

所有场景必须使用相同轨道、姿态、步长、预热圈数和节点参数。

### 11.2 热机制消融

可以比较：

- 完整11节点网络；
- 合并RF与振荡器节点；
- 降低或提高节点间导热；
- 去除外露天线节点；
- 单节点等效模型；
- 不同内部功耗占空比。

比较时优先使用：

- 节点温度振幅；
- 入影/出影延迟；
- 滞回环面积；
- 半仿真码偏差幅值；
- 后续观测模型的修正比例。

### 11.3 参数不确定性

建议对以下参数给出范围而不是单值：

- 表面吸收率和发射率；
- 节点热容；
- 接触导热系数；
- 内部功耗及占空比；
- RF和振荡器温度灵敏度。

每个不确定性样本必须重新传播完整温度历史。不能只对最终温度曲线乘一个比例系数代替热网络变化。

## 12. 数值设置建议

### 12.1 时间步长

默认步长为20 s。建议：

- 初步大范围扫描：30至60 s；
- 正式入影/出影滞后实验：10至20 s；
- 更小热容或更强导热节点：检查5至10 s收敛性。

至少使用两种步长验证主要指标收敛。例如：

```matlab
scenario20 = scenario;
scenario20.timeStepS = 20;

scenario10 = scenario;
scenario10.timeStepS = 10;
```

若RF温度跨度或事件延迟变化超过预定容差，应继续减小步长或检查节点参数。

### 12.2 预热圈数

默认预热30圈。预热用于削弱293.15 K统一初值对正式分析时段的影响。

慢节点、低导热节点或高β无地影场景可能需要更多预热圈。建议比较20、30和50圈，确认正式时段起始温度及第一圈响应稳定。

### 12.3 温度边界

默认积分保护范围：

```matlab
scenario.integration.minimumTemperatureK = 100;
scenario.integration.maximumTemperatureK = 500;
```

超出范围时程序中止。这通常意味着：

- 单位错误；
- 热容或导热系数异常；
- 投影面积重复计算；
- 内部功耗数量级错误；
- 时间步长过大；
- 节点缺少合理散热路径。

不应简单放宽边界后继续使用结果。

## 13. 典型问题排查

### 13.1 找不到 `leotherm` 函数

执行：

```matlab
cd('H:/paper/leo-gnss-thermal-simulator')
startup
rehash
```

不要把 `src/+leotherm` 本身作为工作目录；应把 `src` 加入MATLAB路径。

### 13.2 MATLAB命令行启动后没有输出

先检查MATLAB是否能执行最小命令：

```powershell
matlab -batch "disp(version)"
```

若日志为空且MATLAB进程长期停在初始化阶段，问题发生在许可证、Java、用户首选项或安装环境，还没有执行本项目代码。此时先在MATLAB桌面中手动运行：

```matlab
disp(version)
```

确认MATLAB本身正常后再运行项目测试。

### 13.3 目标β角不可达

这不一定是程序错误。β角的可达范围由日期、太阳赤纬和轨道倾角共同限制。可以：

- 改变日期；
- 改变倾角；
- 使用另一个RAAN解分支；
- 保留该案例为不可达，不得插值替代。

### 13.4 温度振幅过大

依次检查：

1. 面积是否使用平方米；
2. 热容是否使用J/K；
3. 导热系数是否使用W/K；
4. 外表面是否被重复建模；
5. 吸收率和发射率是否在0至1；
6. 内部节点是否具有合理导热路径；
7. 预热是否充分。

### 13.5 温度几乎没有周期变化

检查：

- β角是否过高而没有入影；
- 姿态是否使主要外表面持续对日；
- 节点热容是否过大；
- 节点与结构导热是否过强；
- 太阳直射是否被关闭；
- 分析时段是否过短。

## 14. 论文实验使用原则

正式论文实验建议保存以下内容：

1. 完整场景参数；
2. 完整节点参数和导热矩阵；
3. MATLAB版本与代码版本；
4. 目标β角和实际β角；
5. 不可达和失败案例；
6. 时间步长与预热收敛检查；
7. 温度到码偏差的映射系数；
8. 参数标定数据与独立验证数据的划分；
9. 原始时序、汇总指标和绘图源数据。

以下做法应避免：

- 删除不利案例但不报告筛选规则；
- 用同一组数据标定热参数并评价检测效果；
- 把高β无地影案例与低β周期入影案例直接平均；
- 把人为设置的码偏差幅值称为真实观测结果；
- 仅报告修正模型优于基线，不报告各模型实际修正比例；
- 只做一个节点参数组合而不讨论参数不确定性。

## 15. 推荐运行顺序

首次使用建议按以下顺序：

```matlab
% 1. 初始化
```
