# 术语与指标

软件、任务报告和论文采用相同的物理量名称。指标首次出现时给出计算定义；程序字段名与界面名称分开管理，以兼容已有项目。

| 中文 | English | 定义或单位 |
| --- | --- | --- |
| 集总参数热网络 | Lumped-parameter thermal network | 每个节点用一个温度状态及节点热容表示 |
| 节点热容 | Nodal heat capacity | J/K；不是比热容 J/(kg K) |
| 等效热导 | Effective thermal conductance | 节点间传热功率与温差的比值，W/K |
| 材料导热系数 | Thermal conductivity | 材料参数，W/(m K)；不与节点热导互换 |
| 接触热导 | Thermal contact conductance | 明确接触界面的总热导，W/K |
| 吸收功率 | Absorbed power | W；轨道热滞后的参照为全网络总外部吸收功率 |
| 传热功率 | Heat-transfer rate | W；导热连接的带方向传热量率 |
| 热流密度 | Heat flux | W/m²；不能用于指代单位为 W 的曲线 |
| 温度极差 | Temperature range | 全时段最高温度减最低温度 |
| 温度百分位差 P95-P5 | Percentile temperature difference P95-P5 | 第95百分位数减第5百分位数，不是温度极差 |
| 峰间时延 | Peak-to-peak time lag | 温度峰时刻减吸收功率峰时刻，按轨道周期折叠，单位 s |
| 轨道基频相位时延 | Orbital-frequency phase delay | 轨道基频温度相位减功率相位后，除以负轨道角频率，单位 s |
| 热时间常数 | Thermal time constant | 单阶模型的典型参数 C/G；不能替代多节点系统相位时延 |
| 吸收功率—温度滞回面积 | Absorbed-power–temperature hysteresis area | 完整轨道闭合曲线面积，W K |
| 周期稳态 | Periodic steady state | 相邻周期在相同轨道相位处的温度满足给定收敛条件，并非恒温热平衡 |
| 辐射视因子 | Radiation view factor | 表面间辐射交换的几何因子 |
| 规定温度边界条件 | Prescribed-temperature boundary condition | Dirichlet 条件 |

P95-P5 是本文定义的统计量，不宣称其为独立的行业标准指标。峰间时延与基频相位时延分别按峰时刻及周期分量计算，不互相替换。内部保留 `rfTemperatureSpanK`、`forcingToRfLagS` 等旧字段；新报告导出 `thermal_metric_definitions.csv`，说明它们的名称与定义。

物理术语依据：[NASA 热控说明](https://www.nasa.gov/smallsat-institute/sst-soa/thermal-control/)、[MathWorks 相位时延](https://www.mathworks.com/help/signal/ref/phasedelay.html)。名称以实际公式和代码为准。
