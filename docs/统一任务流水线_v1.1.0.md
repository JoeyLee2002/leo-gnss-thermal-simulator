# 统一任务流水线（v1.1.0）

## 最短路径

1. 启动 `LEOTherm.exe`，或在 MATLAB 中运行 `launch_gui`。
2. 在“快速开始”选择模板，也可打开已有项目。先配置场景与热网络。
3. 在“仿真”顶部勾选需要的阶段：参数扫描、三维耦合、遥测对比、设备标定。四项默认全部关闭；不需要的阶段直接跳过。
4. 点击“检查任务”。只检查已勾选阶段所需的输入、单位、数据覆盖和依赖。缺少输入时，先到对应配置页补齐。
5. 点击“运行任务”，选择一个结果保存位置。软件建立新的任务目录，自动完成后打开“结果与导出”。
6. 点击“打开本次报告 PDF”，核对任务输入、实际执行与跳过的阶段、数值验收和解释边界。原始数据、运行快照与 `pipeline_status.json` 在同一个结果目录。

## 四项可选功能

| 阶段 | 勾选后需要 | 不勾选时 |
| --- | --- | --- |
| 参数扫描 | 扫描模式及相应的高度、β角或日期/倾角/RAAN列表 | 不读取扫描设置，不运行批量案例 |
| 三维耦合 | 已校验的表面和体网格、材料、耦合边界 | 不要求网格或材料；仍运行基础节点热仿真 |
| 遥测对比 | 明确时间和单位的遥测数据、列映射、对比设置 | 不要求遥测文件，也不声称实测验证通过 |
| 设备标定 | 遥测、设备参数范围、训练/验证/测试日划分及验收阈值 | 使用当前热网络，不拟合参数 |

标定与遥测对比是两个开关。只勾选标定时，标定模块仍按自己的划分检查测试日，但不会额外运行“遥测对比”阶段。两者同时勾选且使用同一数据源时，下游对比只使用标定保留的测试日，不使用训练日；不同数据源但时间重叠时预检拒绝运行。

## 每次运行保留什么

每个新目录包含 `input_snapshot.mat`、`frozen_model.mat`、`pipeline_run.mat`、`pipeline_status.json` 和 `report/thermal_report_zh.pdf`（英文任务为 `_en.pdf`）。报告中的“完成/跳过”是本次任务的真实执行记录。数值检查通过不等于物理模型已获得任务级验证；默认网络仍是研究参考模型。

修改配置后，旧报告仍是旧任务的不可变记录；重新运行会建立新目录，不覆盖旧结果。独立版要求 MATLAB Runtime R2021b，但不要求 MATLAB 许可证。
