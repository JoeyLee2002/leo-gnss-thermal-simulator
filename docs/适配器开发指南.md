# 适配器开发指南

本工作台采用 `leotherm.adapter.v1` 扩展契约。适配器负责把外部软件或用户
自有数据转换为工作台已经理解的模型和结果；它不应偷偷转换单位、排序、插值、
补齐缺失数据或猜测节点对应关系。

## 最小适配器

```matlab
adapter = struct;
adapter.id = 'my_exchange';
adapter.version = '1.0.0';
adapter.displayName = 'My exchange adapter';
adapter.kind = 'file_exchange';
adapter.capabilities = struct('readModel', true, 'writeModel', false, ...
    'readResult', false, 'writeResult', false, 'runExternal', false);
adapter.handlers = struct('readModel', @myReadModel);
adapter.provenance = struct('source', 'my_adapter.m');
leotherm.adapter.register(adapter);
```

启用的能力必须提供对应的 MATLAB 函数句柄。JSON 只能保存描述、版本、单位和
来源，不能保存或执行函数句柄。适配器注册后可以通过
`leotherm.adapter.list` 和 `leotherm.adapter.get` 检查。

适配器能力通过统一入口执行：

```matlab
[model, audit] = leotherm.adapter.execute('my_exchange', 'readModel', 'model.json');
```

也可以从 JSON/MAT 元数据描述文件加载，再显式注入 MATLAB handler：

```matlab
[adapter, descriptorReport] = leotherm.adapter.registerFromFile( ...
    'my_adapter.json', 'Handlers', struct('readModel', @myReadModel));
```

描述文件中的 `handlers` 字段必须为空；这样可以避免把不可审计的可执行内容
藏进 JSON/MAT。描述文件来源和格式会写入 `adapter.provenance`。

## 成熟软件接入

软件库提供四个外部工具配置档：Thermal Desktop、ESATAN-TMS、SINDA/FLUINT 和
OpenFOAM。这些配置档是交换/命令行配置，不是专有格式的原生解析器。用户需要
使用自己拥有的官方导出器或许可证，在明确的输入目录生成 MAT、JSON、CSV、Gmsh、
STL/OBJ 或外部软件 case，然后用 `leotherm.io.runExternalThermalSolver` 运行。

```matlab
config.executable = 'C:\\path\\to\\solver.exe';
config.arguments = {'--batch', 'case.in'};
config.inputDirectory = 'C:\\case\\input';
config.outputDirectory = 'C:\\case\\run_001';
config.expectedOutputs = {'temperature.csv'};
config.adapterId = 'thermal_desktop';
config.softwareVersion = 'user supplied';
run = leotherm.io.runExternalThermalSolver(config);
```

运行器不经过 shell，禁止命令元字符，输出目录不得覆盖旧文件，并保存标准输出、
标准错误、退出码、超时状态、输入/输出文件大小和 SHA-256 指纹。外部程序返回非零
退出码、超时或缺少预期输出时，运行器返回完整的失败记录，而不是丢失证据；配置和安全
错误仍然直接拒绝。

## 报告

```matlab
bundle.adapter = leotherm.adapter.get('thermal_desktop');
bundle.externalRun = run;
leotherm.report.writeThermalSimulationReport(bundle, 'report', 'both');
```

报告包括中英文 Markdown、CSV 指标、MAT 审计数据和 JSON manifest。报告会明确
标注：文件交换成功或数值结果一致，不等于热真空、飞行或物理正确性验证。

对于内部三维表面—体网格结果，可使用 `leotherm.writeSurfaceVolumeScenarioResult` 一键导出耦合守恒
诊断、体网格结果和统一中英文报告。当前耦合为单向面片外部辐射到体内导热，面片温度反馈尚未启用，
报告会记录这一边界。

## 扩展边界

- 材料、部件、接触、边界和网格映射仍必须显式提供。
- MATLAB 函数句柄适配器不能直接写入 JSON；跨语言适配器应使用文件或命令行。
- 专有软件格式的版本变化应在适配器版本中记录。
- 适配器应保存来源、软件版本、单位、转换步骤和输入输出指纹。

示例见 `examples/adapters/generic_user_adapter.m`。
