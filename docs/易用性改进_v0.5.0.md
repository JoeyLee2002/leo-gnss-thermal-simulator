# v0.5.0 操作说明

## 软件主线

软件现在按用户任务组织：

`仿真配置 → 运行仿真或扫描 → 查看结果与导出`

主界面只有“仿真”和“结果与导出”两个区域。场景、热网络、遥测和标定都是
仿真的配置或准备工作，不再作为与仿真并列的主功能。

## 仿真区域

“仿真”区域内部包含五个配置页：

- 单场景：设置日期、UTC 时刻、轨道、姿态和环境，点击“运行单场景”。
- 参数扫描：设置扫描范围，点击“运行参数扫描”。
- 热网络：选择或编辑节点、导热和设备角色；网络恢复位于“网络操作”。
- 遥测与验证：导入数据、预检、选择节点和运行验证；模板、演示数据、映射读写位于“更多操作”。
- 设备标定：点击“准备标定”加载当前设备和遥测日期，再点击“标定并保存新运行”。

配置完成后，顶部状态会说明当前结果是否仍对应当前配置。配置修改不会悄悄覆盖旧结果。

## 结果区域

“结果与导出”集中显示指标、摘要、图表和导出操作。“清空界面结果”已经收进“更多操作”，
避免与导出按钮并列造成误点。清空只删除显示结果，不修改仿真配置。

## 项目与工具

顶部保留“保存项目”和“打开项目”两个高频操作。低频功能位于菜单：项目菜单包含项目另存为、
设备配置导入导出；工具菜单包含软件自检和关于。完整项目仍会保存遥测快照、配置、扫描、标定和结果。

## 设计原则

用户只需要记住三个动作：配置仿真、运行仿真、查看结果。内部模块仍然独立实现，便于维护和后续
增加新的热模型或数据源。高级操作没有删除，只是从主路径移到“更多操作”或菜单中。
