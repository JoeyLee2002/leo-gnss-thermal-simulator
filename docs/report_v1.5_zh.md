# v1.5 报告与数据

完整任务的报告在 `report/thermal_report_zh.pdf` 或 `report/thermal_report_en.pdf`。文件名统一为英文，正文、图表和图例由任务语言决定。

论文复现任务同时交付两小时参考仿真、36 工况研究、三个步长加密算例、数值记录和综合 PDF。报告包含环境热流、具名节点温度、热导矩阵、储能与能量核算、轨道条件及热导对比、全节点统计和任务结论。图表来自实际计算数据，不从旧归档复制结论。

`paper_results.csv` 给出各工况的标准化指标；`open_data` 提供温度和外部热流时序；`sweep36` 保留各工况 MAT、原始汇总和加密记录；`paper_study_status.json` 记录已保存的工况数及运行状态。报告中的 `publication_*` 图形与对应源数据可用于论文。

状态 `complete` 表示任务已交付，`cancelled` 表示用户停止。停止后的目录保留已生成的数据，不能作为全部实验完成的证明。软件不会删除用户已经保存的工况。

P95-P5 指第 95 与第 5 温度百分位之差；全时段温度极差指最大值减最小值。轨道频率相位时延以总外部吸收功率为参考。具体标签和定义见 `thermal_metric_definitions.csv`。
