# v0.4.4 操作说明

## 启动与旧版本

在 MATLAB 中运行：

```matlab
cd('H:\paper\leo-gnss-thermal-simulator')
startup
launch_gui('zh')
```

更新前的 v0.4.3 源码和清单位于相邻的
`H:\paper\leo-gnss-thermal-simulator_versions` 文件夹。
历史结果不覆盖；旧版和新版结果应按版本、配置分别比较。

## 单场景仿真

“单场景”页新增“地球红外模型”：

- **有限地球圆盘**：新建场景默认选项，考虑侧向表面看到的部分地球。
- **旧版余弦近似**：用于核对历史结果。导入没有此字段的旧配置时自动保留旧模式。

这里只升级均匀地球红外；地球反照仍使用简化模型，尚不计算星体自身遮挡和表面间辐射。

时间步长仍控制轨道、热输入和输出的采样。积分器在每个采样间隔内自动细化，
防止较小热容或较强导热造成静默数值误差。但它不能恢复未采到的入影、功率开关等变化。
对精确入影时延研究，仍需减小输入采样步长并比较结果。

命令行可读取数值诊断：

```matlab
s = leotherm.defaultScenario;
n = leotherm.defaultReceiverNetwork;
r = leotherm.simulateScenario(s,n);
r.numerics
```

可选精度参数放在 `s.integration` 内：`absoluteToleranceK` 默认 1e-6 K，
`relativeTolerance` 默认 1e-8，`maximumInternalSteps` 默认 1000000。
能量收支闭合仅检查同一数值积分内部的一致性，不代表真实卫星已经验证通过。

## 滞后结果

恒定、小幅到无法数值分辨、长平台或重复峰值等曲线不再报告确定的正滞后。
界面显示“不可识别或不适用”，数值表保留缺失值，不补成零。
新增带符号峰值相位差、采样分辨率和有效周期数。

负的相位差不再绕一个周期包装成长热延迟。峰值相位是两条曲线的相对位置，
不是材料或设备的热时间常数；多峰、多节点响应仍可能有物理相位歧义。
当前幅度筛查是数值门槛，不是依据传感器噪声建立的显著性检验。

## 遥测缺失

驱动数据有效时，某个温度测点缺失只排除该节点、该时刻的评分。
其他测点继续评分，预测继续积分；预测连续不意味着填补了观测温度。
质量不合格的驱动、无效时间或过大时间间隔仍拆段，不插值。
若启用“首个实测温度初始化”，各段首个映射温度必须有效，否则该段明确失败。

## 设备标定

“设备标定”的设置区新增“覆盖要求”标签页，包含四项逐日、逐节点要求：

| 设置 | 默认值 | 含义 |
|---|---:|---|
| 最低有效时长 | 1800 秒 | 真正参与评分的相邻有效区间之和，缺测间隔不计入 |
| 最低连续时长 | 600 秒 | 最长连续有效评分段 |
| 最低温度变化 | 0.5 K | 该日期、该节点评分温度的极差 |
| 最低评分样本数 | 30 | 实际参与评分的测温点数 |

这些值是可修改的工程筛查默认值，不是所有设备通用的认证标准。
按设备时间常数、采样率和研究范围提前设置，不能看完检查集结果再降低门槛争取通过。
三个评分点仍是进行数学比较的最低要求，但不再足以获得验收通过状态。

误差满足但覆盖不足时，状态为“需要复核”。结果区新增“冻结运行：数据覆盖”页，
逐项展示每个日期和节点的数值；导出文件包含 `coverage.csv`，中英文报告也记录门槛。
合成演示通常只有约八分钟，按默认门槛会提示覆盖不足，这是预期行为。

## 仍然存在的边界

本版没有新增真实卫星独立验证证据，也没有增加参数置信区间。
参数硬边界和局部灵敏度诊断继续有效，但不能证明参数唯一、正确地恢复。
后台取消与恢复、更多原始遥测格式、星体遮挡和面间辐射仍需要后续版本。
