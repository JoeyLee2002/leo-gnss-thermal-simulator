# 科研图形导出

## 完整任务

按原有流程选择模板、检查并运行任务。在任务目录的 `report` 子目录中查看报告和图形，无需新增绘图软件。

| 文件 | 用途 |
| --- | --- |
| `thermal_report_zh.pdf` / `thermal_report_en.pdf` | 完整分析报告 |
| `detail_*_zh.png` / `detail_*_en.png` | 各章节原生 MATLAB 图形 |
| 同名 `.pdf` | 矢量图形，适合论文排版 |
| `publication_*_zh.png` / `publication_*_en.png` | 论文组合图，直接来自同一报告绘图函数 |
| `publication_*_source.mat` | 组合图的原始图表数组 |
| `publication_figures_*.json` | 图形与任务阶段的对应关系 |
| `thermal_conductive_links.csv` | 每条双向连接仅记录一次的热导表 |

## 读懂导热矩阵

行列编号对应同一组节点，左侧给出节点名。颜色表示热导大小，格内数值单位为 W/K。空白格表示无直接导热连接；不是漏画，也不表示部件间不存在间接传热路径。对称两个格子表示同一条双向连接。例如参考网络中 7 与 9 的热导均为 0.62 W/K，这是一条连接，不是两条。

此图展示模型输入热导。实际热流还与两端温差有关，应结合下方温差、热流曲线及报告中的平均热流分析一起看。

## 保持报告和论文一致

直接使用同次任务输出的 PNG 或矢量 PDF，不重新拟合、不平滑、不插值。多节点温度曲线每组至多六条，分组后保持相同纵轴范围。零面积和零光学参数保留为零；扫描中没有有限值的指标不生成空图，原始数据仍保留。

逐圈峰值时间差只有一个可评分周期时，用温度分析中的一句话报告，不单独绘图。没有可评分周期时保留文字诊断，两个及以上周期才绘制逐圈图。此规则按可评分周期数判断，不按仿真总时长或正向时延个数判断；负时间差不会被删除。论文响应诊断组合图在省略时延面板后仍导出能量守恒曲线，单图不再标注子图字母。

已归档任务可以重新导出而不重新计算：

```matlab
addpath('src');
saved = load('old_run/report/thermal_report_data.mat', 'bundle');
leotherm.writeThermalReport(saved.bundle, 'new_report_directory', 'both');
```

输出目录必须不存在或为空，防止覆盖以前的报告。图形显示可四舍五入，MAT/CSV 中保留原始数值。计算模型、积分器和验收阈值在本次绘图更新中没有改变。
