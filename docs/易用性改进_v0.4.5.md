# v0.4.5 操作说明

## 启动

在 MATLAB 中运行：

```matlab
cd('H:\paper\leo-gnss-thermal-simulator')
launch_gui('zh')
```

顶部语言选项可切换中文、英文。切换不再把开始时刻改成中午，也不会清空扫描输入。

## 一次完整操作

1. 在“单场景”设置日期和开始时刻。两者均为 UTC，不是电脑本地时间。
   时刻格式为 `03:04:05`，支持小数秒，如 `03:04:05.125`。
2. 选择热网络并检查设备参数。点击固定在参数区下方的“运行单场景”。
3. 查看顶部结果状态。修改轨道或热网络后，旧图保留但会标记为过期，需重新计算。
4. 点击“保存项目”，选择新的 `.mat` 文件。它不只是设备参数，还保存当前遥测、
   列映射、扫描输入与结果、标定配置、日期划分和已有结果。
5. 下次点击“打开项目”即可恢复。CSV 数据内嵌在项目中，原 CSV 移动后仍可使用。

完整项目只接受本软件的项目格式。旧的设备配置文件请通过“项目”菜单中的
“导入设备配置”打开，不要用“打开项目”。请只打开可信来源的 MAT 文件。

## 保存与退出

- 首次保存选择位置；以后保存更新同一项目。
- “项目”菜单提供“另存为”，用于保留不同方案。
- 覆盖保存前，旧项目保留为同目录下的 `项目名.mat.previous`。
  需要恢复时，将该文件复制为新的 `.mat` 文件再打开，不要覆盖当前文件。
- 关闭窗口或打开另一个项目时，若有未保存修改，会询问保存、放弃或取消。
- 本版没有自动保存和崩溃恢复；重要计算完成后请主动保存。

## 遥测先预检

导入数据并检查映射、驱动模式和排除时长后，点击“数据预检”。预检会检查所需字段、
有效驱动行、可用连续段、最长连续时长以及温度观测数量，并指出常见问题。

预检不进行插值，不填补缺失数据，也不运行热求解器。“可运行”不代表数据覆盖充分，
更不代表通过物理验证。轨道驱动仍需确认坐标系和向量定义；标定仍需独立检查日与设备证据。

当单场景结果已经过期时，不允许将它作为遥测验证的参考结果。请先重新运行单场景。
修改遥测映射、选项或设备后，已有遥测结果也会标记过期；重新计算后再导出。

## 参数扫描

扫描显示已处理案例数和总案例数。点击取消后，当前案例先完成，剩余案例记为“已取消”，
不填写虚假的误差或温度值。已完成案例仍可查看、保存和导出。

取消不是立即中断单次积分；长案例仍需等待。界面运行期间锁定输入，避免同一批扫描混用参数。
本版尚不支持后台队列或中断后自动续跑。

## 导出与可追溯性

“结果与导出”导出到新目录，避免覆盖已有输出。即使保留的是旧结果，导出的场景配置也来自
该结果的原始输入，而不是当前改过的参数。`export_metadata.mat` 记录场景和扫描是否过期。

保存项目用于继续工作；导出结果用于分析与共享。二者用途不同。
