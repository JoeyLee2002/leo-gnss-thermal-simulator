# v0.4.2：热边界与参数标定

## 本次解决什么

旧 MinXSS 实测实验中的阴影误差，可能与常数环境热输入、缺少面板至星体的导热有关；
旧版最优标定还存在优化预算耗尽的问题。这不是已经证明求解器方程写错。

本版增加接入真实物理边界的能力，修正标定完成判定，并保留旧结果用于回归。
**功能测试通过，不等于卫星实测验证已经通过。旧的 2.710 K、3/9 日期同时达标结果没有被改写。**

## 1. 边界温度是什么

以太阳能板为例，已知星体连接处温度 `Tb(t)`，面板温度为 `T(t)`，连接导热系数为 `G(t)`：

```text
C dT/dt = 吸收热功率 + 内部功耗 + 网络内部导热 - 向深空辐射
          + G(t) [Tb(t) - T(t)]
```

- 星体比面板热时，热量经连接流入面板；反之流出面板。
- `G` 单位为 W/K，不是热功率 W，也不是时间常数。
- 边界温度应来自独立的连接位置测温，或者有依据的外部物理模型。
- 不能把待验证面板的完整测温序列复制成边界输入，这会形成反馈泄漏。
- 给定边界温度相当于一个外部温度库，不计算面板对该温度库的反作用。
  需要双向耦合的整星预测时，应将星体作为有热容的网络节点，通过对称导热矩阵连接。
- 接入了边界，只能验证“在给定边界下的面板响应”，不能声称边界或整星模型也得到验证。

## 2. 图形界面操作

在 MATLAB 中运行：

```matlab
cd('H:/paper/leo-gnss-thermal-simulator')
launch_gui('zh')
```

1. 打开“遥测与验证”。“合成演示”现在带有一个变化的边界温度通道，可先查看其映射和图例。
2. 准备真实数据时，选择“导出空模板”，再选择“包含边界”。
3. 填写原始时间戳、驱动功率或轨道输入，以及需要连接的节点对应的边界温度和导热系数。
4. 不需要边界的节点，删除其两列，或在导入后的映射表中同时设为“忽略”。不要留下已映射的空列。
5. 在映射表中检查“边界温度”“边界导热系数”、接收热量的节点及单位。
6. 运行后检查输入审计、温度残差和图例。切换中文/英文不会改变数据、参数或计算结果。
7. 导出结果。`thermal_boundaries.csv` 记录边界输入及瞬时导热功率，`manifest.json` 记录条件验证身份。

例如接收机射频节点的列名：

```text
boundary_temperature_k_gnss_rf_frontend
boundary_conductance_wk_gnss_rf_frontend
```

摄氏温度可以使用 `boundary_temperature_c_节点标识`，也可以手动映射为摄氏度。
温度和导热系数必须成对。每个节点支持一个有效外部温度库。
未连接节点内部占位温度不具有物理输入意义，导热严格为零，也不会导出为实测边界。

## 3. 不插值规则

沿用原始观测历元。坏行和超限时间间隔均断段，下一段重新初始化。
不排序修复时间、不跨缺口连接、不补齐缺测。

在两个有效相邻样本之间，边界温度及导热系数按区间左端保持。
这是规定采样输入的积分规则，不是恢复缺失观测。若输入变化快，应提供更密的真实采样，
或评估左端保持近似的误差，不得把计算子步当成新观测。

负导热系数、非正开尔文温度、无穷值、缺失值都不能用于计算。
强导热时会额外限制 RK4 内部步长；这不改变原始输出历元，也不是刚性隐式求解器。
极强耦合可能需要很多子步，运行较慢。

导出的 `boundary_heat_w_*` 是采样点瞬时热流，正值为流入。
它使用该时刻的边界值，不是前一个积分区间的平均功率或累计能量。

## 4. MATLAB 接口

普通热求解器新增两个可选字段，均为“历元数 × 节点数”矩阵：

```matlab
forcing.boundaryTemperatureK = boundaryK;
forcing.boundaryConductanceWK = conductanceWK;
forcing.holdPrevious = true;
forcing.maxStepS = 5;
temperatureK = leotherm.solveThermalNetwork(timeS, externalW, network, ...
    scenario.environment, scenario.integration, forcing);
```

不传边界时保持旧行为。传入边界时，边界本身始终左端保持；旧版非遥测接口的外部功率
是否线性变化仍由 `holdPrevious` 控制。通过遥测界面运行时全部驱动采用左端保持。

## 5. MinXSS 面板接口

`studies/minxss/minxss_panel_predict.m` 增加：

- `input.environmentPowerW`：历元数 × 2，两块板的非负环境输入功率。
- `input.boundaryTemperatureK`：历元数 × 2，独立星体连接边界温度。
- `input.hingeConductanceWK`：历元数 × 2，板至星体的有效连接导热系数。

两块板顺序为负 Y 板、正 Y 板。双节点模型将星体边界连接至基板，不直接连接电池片。
该简化接口的环境热输入也施加在基板；它不是前后表面分别求解的精细辐射几何模型。
提供变化环境输入时，原参数中的两项常数环境功率必须设为零，否则拒绝计算，防止重复计入。
标定时不要再把这两项零常数作为自由参数；可以在训练目标函数中把较短参数向量组装为模型参数。

**旧实验的原始数据尚不足以确认连接处测点及对应导热系数，因此旧实测流程不会自动开启这些项。**
本次也没有把其他位置的遥测温度冒充连接处温度，没有根据测试残差反推一条外部热输入。
地球红外、反照率与有限地球盘视因子的更精细轨道重建仍未完成。

## 6. 更可靠的参数标定

```matlab
bounds.lower = [20 0.02];
bounds.upper = [250 0.60];
bounds.initial = [90 0.20];
settings = struct('starts',4, 'solver','auto', ...
    'maximumIterations',1200, 'maximumEvaluations',5000);
% trainingObjective 必须只使用训练数据，返回有限的标量损失。
fit = leotherm.fitThermalParameters(trainingObjective, bounds, settings);
leotherm.requireCalibrationConvergence(fit);
```

`auto` 在有许可证时使用 Optimization Toolbox 的 `fmincon`；否则使用基础 MATLAB 的
`fminsearch` 加归一化盒约束罚项。可显式指定算法以便跨机器复现。没有新增第三方运行时依赖。

新流程记录所有起点的结果、实际算法、退出标志、有限差分投影梯度、近边界参数及多起点参数分散程度。
默认采用确定性分散起点，也允许传入 `settings.initialPoints`，每行为一个起点。
归一化投影梯度检查是停止诊断，不是严格的物理可辨识性证明。

`fit.converged` 要求优化器正常退出，并通过额外的归一化投影梯度检查。
预算耗尽不会被当成成功。保留未收敛最优候选及警告，不偷偷换成损失更差的已收敛候选。
MinXSS 流程会在冻结前检查两个模型，未通过就停止，保留拟合文件和逐起点检查点。
检查点拒绝覆盖，重新运行需使用新目录。

`parameterInstability` 提示相近损失下出现明显不同参数；
`parameterStabilityAssessed=false` 表示没有足够的近优起点用于比较。
这些都不能替代参数剖面、独立激励工况或传感器不确定度分析。
本版不会自动宣称参数唯一或已找到全局最优。

## 7. 旧数据的证据身份

旧 MinXSS 日期已被查看并用于发现模型不足。新版本继续使用它们时必须叫开发复算，
不能再次声称是新的独立验证。新协议和报告已明确这一点。
新独立检验必须使用未参与调试的数据，并在查看结果前固定模型、参数、筛选规则和指标。

本版测试、界面截图与旧预测回归只回答“软件是否按设计工作”，不回答“新增物理项是否已获在轨验证”。
