# LEOTherm 免安装版

## 用户只需三步

1. 下载名称包含 `portable` 的完整免安装包。GitHub 的“Download ZIP”是源代码，不是免安装软件；旧的小压缩包仍需要单独安装 Runtime。
2. **完整解压**到纯英文路径，例如 `C:\LEOTherm`。不要在压缩包内直接运行，也不要拆散 `app`、`runtime` 文件夹。
3. 双击 **Start_LEOTherm.exe**。首次使用阅读并确认随包附带的 Runtime 许可，然后选择模板、检查任务、运行，最后查看分析 PDF。

用户不需要安装 MATLAB，不需要 MATLAB 许可证，也不需要另外安装 Runtime、配置环境变量或使用管理员权限。运行库仍然存在，只是随软件一起提供。因此下载包较大，解压后约需 8 GB 以上磁盘空间，另需预留缓存和结果空间。首次启动需要展开程序缓存，请耐心等待，不要连续重复双击。

## 能做什么与边界

免安装版沿用现有 1.2.1 仿真程序和任务流水线，不改热学方程。节点仿真、参数扫描以及用户配置的可选阶段仍按原有输入和依赖运行。外部求解器及用户自己的遥测数据不随包提供，不能因为免安装就认为这些依赖也自动具备。

本版是 Windows 64 位包，不是 Linux/macOS 通用包。启动器使用 Windows 的 .NET Framework 4.x，目标环境须兼容 MATLAB Runtime R2021b。尚不能声称所有 Windows 环境均已实测通过。软件没有数字签名，单位安全策略可能要求审核；不要关闭防护或绕过安全限制。

仿真成功不代表在轨物理验证。之前发现的报告工具栏、缺省字段等应用层问题，也不会被免安装打包自动修好。

## 数据放在哪里

- 程序：解压目录，包含启动器、`app`、完整 `runtime/v911`、模板和使用说明。
- 仿真结果：运行任务时选择的输出目录，包含 PDF、数据和运行记录。
- 缓存、启动日志和首次许可确认：`%LOCALAPPDATA%\LEOTherm\Portable`。

启动器只给本次子进程临时设置 Runtime 路径，不修改系统/用户 PATH 或注册表。“免安装”不是“完全不写磁盘”；删除程序文件夹不会删除已经保存的报告，也不会自动清理用户缓存。

服务器没有 PDF 阅读器时，报告仍会生成，但 Windows 可能打不开。可以把 PDF 取回有阅读器的电脑查看；本包不会擅自安装阅读器。

## 出现问题时

保留 `%LOCALAPPDATA%\LEOTherm\Portable\logs` 中最新日志。检查是否完整解压、路径是否纯英文、是否误下载了源代码或旧版小包。不要混用不同 Runtime 版本，也不要只复制内部的 `app/LEOTherm.exe`。

开发者可用 `--diagnose` 导出启动前检查结果，或用 `--smoke` 执行小型仿真至 PDF 的验收。前者只检查关键文件，后者不替代人工界面验收。具体命令见英文说明。

随附 Runtime 采用 MathWorks 自己的许可证，不因软件开源而变成开源。许可证和法律声明完整保留，首次确认由用户自己完成。
