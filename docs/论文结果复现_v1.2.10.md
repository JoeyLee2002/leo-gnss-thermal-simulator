# 论文结果复现（v1.2.10）

## 图形界面

1. 启动 LEOTherm；在“快速开始 / Quick start”选择“复现论文：参考任务与36工况 / Paper: reference task and 36 cases”。
2. 点击“复现论文并生成报告 / Reproduce paper and report”。
3. 选择结果保存的父目录。软件自动创建独立任务目录，不覆盖已有结果；当前工作区设置不变。
4. 等待参考任务、36工况、3个加密算例和报告完成。完成后打开当前语言 PDF。

本入口使用固定论文配置，不读取旧 CSV 作为计算结果。切换语言只改变展示，不改变求解参数。

## MATLAB 源码入口

```matlab
addpath('src');
study = leotherm.runPaperStudy(fullfile(pwd,'results','my_paper_run'),'both');
```

输出目录必须尚不存在。`both` 导出中文、英文报告；`zh`、`en` 只导出相应语言。

## Windows Runtime 入口

安装匹配的免费 MATLAB Runtime R2021b 后，使用新版可执行程序：

```powershell
.\LEOTherm.exe --paper-study "C:\LEOThermResults\paper_run_01" both
```

## 固定实验

参考任务：默认11节点网络、600 km对地定向、7200 s、60 s输出间隔，不预热。

36工况：400/600/800 km × 0°/30°/60°/75°目标 β 角 × 0.31/0.62/1.24 W/K 结构—射频前端等效热导。采用固定太阳方向，先周期初始化（温差不超过0.001 K），再分析6圈，每圈360个输出间隔。第2、20、36工况以720个间隔独立重算。其他模型参数保持相同，不对缺失观测插值。

## 输出与判读

| 文件 | 内容 |
| --- | --- |
| `paper_study_status.json` | 当前阶段与最终状态；成功为 `complete`，工况数36 |
| `paper_results.csv` | 单位明确的三因素与结果列 |
| `audit.csv` | 因子唯一性、周期收敛、单一连接变化、外部功率一致性、能量闭合 |
| `sweep36/protocol.json` | 完整输入与单位 |
| `sweep36/time_refinement.csv` | 三个加密算例的差值 |
| `open_data/*.csv` | 全36工况温度和外部吸收功率时间序列 |
| `report/thermal_report_zh.pdf`、`thermal_report_en.pdf` | 参考任务和36工况的图表、配对效应及总结 |
| `report/publication_paper_study_*.png` | 与论文共用的原生 MATLAB 图 |
| `report/thermal_metric_definitions.csv` | 中英文指标名称与定义 |
| `paper_study.mat` | 当前计算的原始结果与报告数据 |

射频前端 P95-P5 是第95与第5温度百分位数之差，不是完整极差。相位时延相对于所有节点吸收的外部功率总和，单位为秒，不是材料热时间常数。

论文量级：P95-P5约0.995–6.048 K；热导从0.31增至1.24 W/K，入影工况增加约8.4–39.7%，持续光照工况减少约10.5–12.1%；12组配对相位时延缩短约36.8–131.0 s。这些区间由本次36工况计算生成，而非写入报告的固定结论。
