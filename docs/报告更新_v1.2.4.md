# v1.2.4 报告与计算更新

## 本次改了哪些软件功能

1. 周期响应采用新增的轨道基频相位分析。计算直接进入仿真指标和参数扫描，报告读取同一套实现。
2. 原来的逐圈峰值时间差保留，供查看各圈峰的位置；它与轨道基频相位是两个名称和定义均不同的指标。
3. PDF 改为单页输出、一次合并、重开核对页数后再生成最终文件。合并调用 MATLAB/Runtime 自带的 Apache PDFBox。
4. 节点图直接标设备名称；热导矩阵改成连接示意图；所有连接的 W/K 数值随报告导出 CSV。
5. 内部节点的零面积、零光学系数直接标 0；固定采样间隔仅在任务信息中列数值。
6. 删除“阅读结论”和泛泛的分析语句，使用实际温度范围、节点名称、光影次数和热流数值。

## 时延现在是什么

先在实际采样时刻同时拟合常数、线性趋势、前三阶轨道谐波，再取热流和温度的第一阶分量相位差。
等效相位时延为相位差除以轨道角频率，使用正负半圈范围内的主值。
正值表示该频率上温度响应在热流之后，负值表示相位超前。

这里比较的是全网络外部吸热与指定响应节点温度的周期分量。
它是周期响应的描述量，不与材料时间常数、纯传输时间或逐圈最高峰时间差混用。
三圈以上且采样满足要求的任务会生成基频对比图；常量信号等情形返回明确的适用状态。
没有补齐、插值原始数据，也没有为得到特定时延调整热网络参数。

已保存项目中的旧指标数值保持原定义。重新导出时，新指标从保存的温度和热流时序重新计算。
在扫描 CSV 中，新列为 `orbital_phase_delay_s`；原峰值列保持原含义。

## 如何使用

源代码用户启动新版 GUI；独立版用户解压新应用包并使用已有 Runtime R2021b。
不要把小应用包覆盖到带完整性校验的旧免安装整包中。
运行新任务或加载已有结果后，导出到新的空目录。旧报告和旧任务原件保持原样。
中文和英文报告使用同一组数据、同一套计算，只切换显示文字。
