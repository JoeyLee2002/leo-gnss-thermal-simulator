# 报告样例

`reference_network_sweep_sample_v1.2.0_zh.pdf` 是 v1.2.0 实际运行生成的五页中文报告。

- 基础场景：参考热网络，2 小时、60 秒步长、无预热。
- 扫描：轨道高度 500/600 km，目标β角 0/15/30 度，共 6 个工况。
- 其余可选阶段未运行，在验收页标为跳过。

这个样例用于展示报告分析与排版。默认网络、码偏差灵敏度和快速场景均不是某颗真实卫星的标定值；无预热的温度跨度及时延尤其不应作为科学结论。
# v1.5 随包示例

`thermal_report_v1.5_en.pdf` 和 `thermal_report_v1.5_zh.pdf` 由 v1.5 Runtime 可执行程序新计算的 120 s 参考场景生成，用于展示启动与报告输出，不是论文的 36 工况结果。论文结果请从初始页的论文复现入口重新生成。旧版参考报告仍保留原来的版本名。
